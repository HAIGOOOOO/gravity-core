# 題目 000: ルールを変える（方針の版 9、2026-10-20。全員）

持ち主の言葉（2026-10-19〜20）:「改めてこのプロジェクトを見ると、良いものになるとは思わない」「特にルールと気持ちよさ」→ ゲーム全体の調べ物（5 本の芋づる、原文 188 本）の要点を見て「ルールは良いよそれで」。

## なぜ変えるか（調べ物で分かった事）
- 公式の **Suika Game Planet**（2025-12、Steam）が「円形の盤面・中心へ落とす・360 度」。今の基本操作（押して離す＝核へまっすぐ落とす）とほぼ同じ。「重力に撃つ＋合体＋連鎖」も Planet Merge（iOS 版・Poki 版）がすでにある。
- 被っていないのは、熱量で終わる事、限界リング、Tier 8 の超新星、試作のワンポチ（重力弾・崩壊）だけ。**円形のスイカのままでは勝てない。差は「撃った後に 1 手だけ手を出せる事」と「連鎖しないと熱量で死ぬ緊張」から作る。**

## 進め方
- **持ち主（2026-10-20）: リーダー（Claude）は使わない。担当の Codex がやる。** 仕組み（`src/game/`、`src/contracts/`、`docs/RULES.md`、数値）は **C** が変える（自動チェックは C にだけ開けてある）。D は画面と文字（1 の段の名前の文字、7 の負けた画面）。
- **C は、題目 00「脳汁」より先にこれをやる。** 順番は 2 → 4 → 5 → 1 の出来事 → 3 → 6 → 7 の出来事。1 つ変えるごとに、`npm test`（決まった種で同じ結果になる試験を含む）と typecheck を通し、`docs/RULES.md` を書き直し、進み具合に「題目 000 の n 番: 済み」と書く。
- 数値は `src/game/constants.ts` に足す。熱量の下げ幅などは、まず仮の値で入れ、ボット（`src/tools/` は読むだけでよい。同じ考えのボットを `src/dev/` に作ってよい）で比べて決める。測った数を進み具合に書く。
- 再生の記録（`REPLAY_FORMAT`）と共有の文字列（`SHARE_RULES_VERSION`）は、ルールが変わったら番号を上げる（古い記録で違う結果が出ないように）。
- D は、C の出来事が main に入るまでは題目 00 を続け、入ったら 1 の文字と 7 の画面に取りかかる。
- 提出の合否は、リーダーが別の審査役（安い係）と見る。
- 原文の場所と抜き書きは持ち主の手元（`research/gravity_core_whole/` の 5 本）。要点は `docs/research/` に置く予定。
