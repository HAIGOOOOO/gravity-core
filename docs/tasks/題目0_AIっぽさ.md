# 題目 0: AI っぽさを消す（担当 C・D 共通。方針の版 5、2026-10-17）

持ち主の言葉:「AI っぽい UI やデザインが多く見られる」。
いまのゲームと見本ページには、**AI が作ったと一目で分かる形**が多く残っています。これを、調べて、言葉にして、自分の担当の場所から消し、この先の全部の題目で二度と出さない仕組みにします。

やる順番は、**突き返し → この題目 0 → 自分の担当の題目**です（`docs/方針.md`）。

## 0. 何が「AI っぽい」のか（出発点。これで足りると思わない）

リーダーが今の見本で気づいた物です。**調べ物の代わりにしない。** 調べた結果、違うと思った物は理由を書いて外してよい。

- **見た目（D）**: 小さい英字の見出し（`GRAVITY CORE / VISUAL STUDIES / 01` のような肩書き）。「重さの、見え方。」のような、読点と句点で区切った気取った大見出し。角の丸いカード、細い枠のボタンを横に並べた列。どこも同じ太さの線と同じ余白。意味のない光り方、グラデーション、すりガラス。左右対称・中央寄せ。十字の星や「!」の赤丸のような、どこかで見た記号。全部の色が同じ明るさ。
- **動き（C）**: 全部の動きが同じ速さの曲線（同じ ease-out、同じ 300ms 前後）。全部の物が同じように弾む。意味のない粒・光・紙吹雪。何にでも付く拡大と縮小。全部が同時に出て、同時に消える。強さの差が無い。
- **言葉（両方。画面の文字は D、演出の文字は C）**: 「〜の、〜。」「〜しよう！」「さあ、〜」の決まり文句。中身の無い形容。説明しすぎる文。英語の単語の飾り。
- **作り方**: 見本ページが毎回同じ構成（見出し → 説明 → ボタンの列 → 3 列のカード）。3 案が色違い。

## 1. 調べる（妥協しない）
- **持ち主側の調べ物（2026-10-19）**: `docs/research/2026-10-19_AIっぽさ_要点.md`。芯は「暗い地＋発光色そのものが AI っぽさの型」「主色を 1 つに決めて押し切る」「宇宙は実物の参照から」「色は意味に結ぶ」「制約を先に決める」。30 件の一部に使ってよいが、写さず、実物を見て自分の言葉で。

**量と質の両方を守る。** 足りないまま次へ進まない。

- **集める物（合計 30 件以上）**
  - AI が作った UI・デザイン・文・動きの「見分け方」を論じた物 **10 件以上**。デザイナー本人の文章、講演（GDC、Config など）、デザイン批評、研究。2024〜2026 年の物を中心に、日本語の物も 3 件以上。
  - **人が作って評価された実物 15 件以上**（賞を取った・長く売れたゲームの画面と動き、印刷物、道具の盤面、映像）。実際の画面写真や動画を見て、何が「人が決めた」と感じさせるのかを、具体的に書く（例:「見出しの字間が場所ごとに違う」「1 か所だけ極端に大きい」）。
  - 反対の意見・限界を論じた物 **3 件以上**（「AI っぽい」と言われる形でも良い場合、など）。
- **1 件ごとに書く事**: 名前、URL、作者、日付、**何が書いてあった／何が見えたか（自分の言葉で 2〜4 行。写さない）**、このゲームにどう使えるか、信用できる度合い（実物を見た／人の意見／根拠が薄い）。
- 調べただけで終わらせない。**「AI っぽさの見分け方」を 20 項目以上**の表にまとめる。1 項目ごとに: 見分け方（誰が見ても判定できる言い方）、なぜそう見えるか、代わりに何をするか、根拠（上の何番）。
- ウェブを調べられない環境だったら、その事を進み具合と 6 行の報告に書く。記憶だけで 30 件を埋めない。
- 置き場所: `docs/notes/<担当>/AIっぽさ_調べ物.md`（1 件ずつ）と `docs/notes/<担当>/AIっぽさ_見分け方.md`（20 項目以上の表）。

## 2. 今の物を検品する

- 自分の担当の場所の**今の物全部**（ゲーム本体の画面、見本ページ、文字）を、1 の表で 1 つずつ検品する。見つけた物を、重い順に一覧にする（場所、どの項目に当たるか、画面写真）。
- 他の担当の場所で見つけた物も一覧に書いてよい（直すのは、その担当か、自分の担当が全部合格してから）。

## 3. 直す（実装に組み込む）

- 一覧の重い物から直す。**1 か所ずつ**。直した物は、同じカメラ・同じ場面の前後の画像（動きは前後の動画）で残す。
- 直す時も 1.5 章の周回（3 案 → 選ぶ → 作る → 審査 → 測る）で回す。「AI っぽい形を消して、別の AI っぽい形に変えた」にならないように。
- **これから作る物すべてに組み込む**: 自分の担当のこれからの全部の題目で、審査役への質問に、下の 4 章の質問を必ず足す。見分け方の表に当たる物は、提出しない。

## 4. 審査（AGENTS.md 1.6 章に足す）

審査役に、作り手の説明なしで、画面写真か動画だけを見せて、いつもの質問の後にこれを聞く。

```
この画面（動き）は、AI が作った物に見えますか。見えるなら、そう感じさせた所を、
多い順に 5 つ挙げてください。それぞれ「どこが」「なぜそう見えるか」を 1 行で。
```

- 測る基準:
  - [ ] 審査役が挙げる「AI っぽい所」が、直す前の半分以下になる（同じ質問・同じ場面で比べる）
  - [ ] 見分け方の表の項目に、自分の担当の場所で当たる物が 0（当たる物は、理由を書いて残す事だけ認める）
  - [ ] 調べ物 30 件以上、見分け方 20 項目以上、日本語 3 件以上、反対の意見 3 件以上

## 5. サブエージェントの数（持ち主の指示、2026-10-17）

- この題目でも、ほかの題目でも、**1 つの担当が同時に立てるサブエージェントは 1 体まで**（担当の AI 本人＋1 体＝2 体）。調べる役と審査役を同時に立てない。順番に立てる。
- 審査役の 2 つの役（初見の人・落とす人）は、1 体ずつ順番に立てる。

## 6. 提出

- 進み具合の「題目の状態」に `0 AI っぽさを消す` の行を足す。直した物が一覧の重い物の上から 5 か所に届き、4 章の基準を満たしたら「提出」。その後も、自分の担当の題目の中で、見つけるたびに直す。
- リーダーは、C と D の見分け方の表をまとめて、全員の決まりにする（`docs/AIっぽさ.md`）。まとまったら、それが勝つ。
