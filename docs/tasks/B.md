# 担当 B の手順書 — 盤面と照準

あなたが作るのは「プレイヤーが見る盤面」と「撃つ操作」です。ゲームの主役の部分で、見た目の印象はほぼここで決まります。

- 作る部品: `createBoardRenderer`（`src/render/index.ts`）、`drawBody`（`src/render/bodies.ts`）、`createPointerInput`（`src/input/index.ts`）
- 形の決まり: `src/contracts/app.ts` の「担当 B」の部分
- 確かめる場所: `npm run dev` → `http://localhost:5173/dev/board.html`（上のボタンで盤面を切り替えられる）
- いまある【仮実装】は、単色の丸と 1 本の線だけ。全部作り直してよい。
- 演出（粒子、輪、浮き文字、揺れ）と音は担当 C、HUD とメニューは担当 D。**盤面の Canvas に描くのは下の手順に書いた物だけ。**

各手順の最後に、AGENTS.md「2. 作業の流れ」の 4 つ（チェック → progress 更新 → commit と push → Pull Request）を必ず行う。

## 手順 1: 背景、ガイド、核、熱量リング

読む所: SPEC.md 6.5（1〜3、6、7）、5.1、6.1

- 背景のグラデーション、星 120 個（位置は固定の種から。動かさない）、ガイドの円（半径 160・280）、射出リング（半径 405、破線）、外縁（半径 478）。
- 核（半径 48）と外側の光（半径 70 まで）。熱量の状態（安定・上昇・過熱・臨界）で光の広さと脈動が変わる（過熱は 1.2 秒周期、臨界は 0.5 秒周期）。
- 熱量リング（半径 60、幅 4、真上から時計回りに 熱量 ÷ 100）。色は `src/shared/heat.ts` の `HEAT_STATE_COLOR`。
- `frame.dimmed` が true のときは盤面全体を暗くする。`frame.reducedMotion` が true のときは脈動を止める。
- 星やガイドなど変わらない物は、毎フレーム描き直さずに別の Canvas（`document.createElement('canvas')`）へ 1 回描いて貼る。`resize` のたびに作り直す。

## 手順 2: 天体の描き分け、補間、軌跡

読む所: SPEC.md 4.2、6.5（4、5）、8.2

- `drawBody` を Tier 0〜8 の描き方に作り直す。**関数の名前と引数は変えない**（担当 C・D も使う）。
  - 引数の座標と半径は、呼び出し側の座標系のまま使う。HUD から小さく（半径 8〜30 くらいで）呼ばれても崩れないこと。
  - 模様の位置は `options.seed`（天体の ID）から決め、フレームごとに変わらないようにする。
  - 色だけでなく、輪郭と模様で見分けられること（Tier 5 と 6 は色が近い）。
- 盤面では、`prev` と `curr` の位置を `alpha` で補間して描く。`prev` に無い天体（生まれたばかり）は `curr` の位置で描く。
- 軌跡: 各天体の直近 0.8 秒。位置の記録は 1 体あたり 24 点の固定長。天体が消えたら記録も捨てる。半径 440 を超えた天体の軌跡は `--danger` 色。`reducedMotion` のときは軌跡なし。
- 軌跡の記録は描画側で持ってよい（これは「表示のための記録」で、ゲームの状態ではない）。

## 手順 4: ポインター入力

読む所: SPEC.md 3.4、7.1、7.3、7.4、定数 `AIM_MIN_RADIUS` `DRAG_MIN_PX` `DRAG_MAX_PX`

- `createPointerInput` を作り直す。Pointer Events で、マウスもタッチも同じ動き。
- 押した位置の角度が射出点。動かした向きが飛ぶ向き。距離から速さ（`src/shared/launch.ts` の `dragToSpeed`）。
- `setPointerCapture` で、指が盤面の外へ出ても続ける。
- 取り消し: `cancel()` が呼ばれたとき、マウスの右ボタン、2 本目の指、`pointercancel`。取り消したら `onAim(null)`。
- ドラッグ 24px 未満で離したら `onTapOnly()`。無効な照準（`invalid`）で離したら何も呼ばない。有効なら `onLaunch(command)`。
- **待ち時間中（`rejectReason === 'cooldown'`）は無効にしない。** 照準はでき、離したら `onLaunch` を呼ぶ（待ち時間が明けた瞬間に撃つ処理はアプリ側にある）。
- 予測（`deps.predict`）を呼ぶのは、ポインターが動いたときだけ、最大でも 33 ミリ秒に 1 回。
- `setEnabled(false)` の間は照準を始めない。進行中の照準は取り消す。
- 速さの変換や角度の計算など、純粋な計算は関数に分けてテストを書く（`src/input/*.test.ts`）。

完了条件:
- [ ] 見本ページで、ドラッグした向きへ飛ぶ。タップだけでは撃たれない（右下の記録に「タップだけ」と出る）
- [ ] 盤面の中心付近（半径 120 未満）を押しても照準が始まらない
- [ ] 照準中に右クリックすると取り消される
- [ ] スマホ幅（開発者ツールの端末表示）で、ドラッグ中にページがスクロールしない

## 手順 5: 照準の表示と初回の案内

読む所: SPEC.md 7.2（表の全部）、7.6、3.8

`frame.aim` が null でないときに描く。

- 半透明の天体（透明度 60%）、速さの輪、予測線（手前 80% → 先端 10%）。
- 予測線の色: `prediction.fate` が `orbit` なら `--text`、`core`・`outside` なら `--danger`。
- 終点の印: `prediction.end` が `core` なら × 印、`outside` なら外向きの矢印。
- 時刻マーカー（`prediction.markers`、半径 3）と、相手のマーカー（`prediction.rivals[].markers`、透明度 50%）。`frame.timeMarkers` が false なら出さない。
- 出会いの強調: `rivals[].meetAt` が null でない相手について、`meetX`・`meetY` に半径 6 の印を出し、相手の天体と細い線で結ぶ。`canMerge` が true なら `--cool`、false なら `--warn`。
- 無効の表示: `aim.invalid` が true のとき、半透明の天体と予測線を `--danger` に。
- 初回の案内: `frame.guide` が null でなく、照準していないとき、その位置に半径 18 の脈打つ輪と、向きを示す矢印（長さは `guide.dragPx` を `cssToLogicalLength` で論理座標にした値）。照準を始めたら、輪は残して矢印を薄くする。
