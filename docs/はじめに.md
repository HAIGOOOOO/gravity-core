# はじめに（チームの人向け）

やることは 3 つだけです。コードを読む必要も、書く必要もありません。

| 担当 | 作る物 |
|---|---|
| **B** | 盤面と照準（天体の絵、撃つ操作） |
| **C** | 演出と音（合体の光、効果音） |
| **D** | 画面・保存・ランキング（タイトル、結果、ランキングページ） |

AI に言う一言は、全員同じです。

```
今日の作業をやって
```

AI は、あなたの GitHub のユーザー名から担当を判断します（`docs/TEAM.md`）。判断できないときは聞いてくるので、「担当 C」のように答えてください。

## 1. 最初に 1 回だけ

1. GitHub のユーザー名をリーダーに伝える。
2. GitHub から招待のメールが届くので、**Accept invitation** を押す。
3. Codex（ChatGPT のアプリ）を開き、次のように頼む。

   ```
   https://github.com/HAIGOOOOO/gravity-core を clone して、そのフォルダで作業して
   ```

   GitHub へのログインを求められたら、自分のアカウントでログインします。
   （ブラウザ版の Codex を使う場合は、設定で GitHub をつなぎ、リポジトリ一覧から `gravity-core` を選びます。）

## 2. 毎回やること

1. `今日の作業をやって` と打つ。
2. AI は、止められるまで手順を順番に進め続けます。手順が 1 つ終わるたびに、1 行で知らせてきます。
3. **やめたいときは `中断して` と打つ。** AI はそこまでを保存して止まり、5 行の報告を出します。
   - **見る場所**: 書かれている URL をブラウザで開くと、できた物を触れます。
   - **あなたがやること**: 「Create pull request を押してください」などと書かれていたら、そのリンクを開いてボタンを押す。「なし」なら何もしなくてよい。
4. 次の日は、また `今日の作業をやって` と打てば続きから始まります。手順は担当ごとに 6 つあります。

## 3. 途中で止まったら

- **利用枠が切れた、エラーで止まった**: 枠が戻ってから、`今日の作業をやって` をもう一度打つだけです。AI は `docs/progress/` の記録を読んで、続きから始めます。
- **AI が質問してきた**: 分かる範囲で答える。分からなければ「AGENTS.md の 5 章のとおりに、リーダーへの依頼として書いて、進められる所を進めて」と返す。
- **Pull Request に赤い × が付いた**: `Pull Request の自動チェックが失敗している。原因を調べて直して` と AI に言う。
- それでも進まないとき: リーダーに、AI の最後の返事をそのまま送る。

## 4. やらないこと

- AI に、自分の担当以外の作業を頼まない（ほかの人の作業とぶつかります）。
- AI に「main に直接入れて」と頼まない。取り込むのはリーダーです。

## 5. 進み具合を見たいとき

GitHub のリポジトリで `docs/progress/` の自分の担当のファイル（`B.md` など）を開くと、一番上に「いま」と「つぎ」が書いてあります。
