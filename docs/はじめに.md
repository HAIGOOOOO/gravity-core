# はじめに（チームの人向け）

やることは 3 つだけです。コードを読む必要も、書く必要もありません。

| 担当 | 持つ物 |
|---|---|
| **B** | 続ける（プレイの再生、図鑑、解放、日替わり勝負、記録） |
| **C** | 感じる（合体の演出、効果音、プレイで変わる曲、手触り） |
| **D** | 見る（天体の絵、盤面、全部の画面、入口の演出） |

2026-10-12 に、作り方が変わりました。前は「6 つの手順で終わり」でしたが、今は**終わりがありません**。AI が、1 つずつ何周も作り直して、少しずつ良くしていきます。あなたは、時々一言打つだけです。

## 1. 最初に 1 回だけ

1. GitHub のユーザー名をリーダーに伝える。
2. GitHub から招待のメールが届くので、**Accept invitation** を押す。
3. Codex（ChatGPT のアプリ）を開き、次のように頼む。

   ```
   https://github.com/HAIGOOOOO/gravity-core を clone して、そのフォルダで作業して
   ```

   GitHub へのログインを求められたら、自分のアカウントでログインします。

## 2. 毎回やること

1. 次の一言を打つ。

   ```
   今日の作業をやって
   ```

2. AI は、**止められるまで、ずっと作り続けます。** 1 周終わるたびに、1 行で知らせてきます。放っておいて大丈夫です。
3. **やめたいときは `中断して` と打つ。** AI はそこまでを保存して止まり、短い報告を出します。
4. 利用枠が切れて止まったら、枠が戻ってから、また `今日の作業をやって` と打つ。続きから始まります。

**できれば、枠が戻るたびに 1 回打ってください。** それだけで進みます。3 日動きが無いと、リーダーに知らせが行き、リーダーが代わりに進めます。

## 3. 途中で止まったら

- **AI が質問してきた**: 分かる範囲で答える。分からなければ「AGENTS.md の 5 章のとおりに、リーダーへの依頼として書いて、進められる所を進めて」と返す。
- **Pull Request に赤い × が付いた**: `Pull Request の自動チェックが失敗している。原因を調べて直して` と AI に言う。
- **AI が「全部終わりました」と言って止まった**: 終わりは無いはずです。`AGENTS.md を読み直して、一番弱い題目をもう一度周回して` と返す。
- それでも進まないとき: リーダーに、AI の最後の返事をそのまま送る。

## 4. やらないこと

- AI に、自分の担当以外の作業を頼まない（ほかの人の作業とぶつかります）。
- AI に「main に直接入れて」と頼まない。取り込むのはリーダーです。
