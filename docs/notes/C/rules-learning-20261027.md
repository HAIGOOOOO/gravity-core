## 連投の3案

1. 同じ本体計算の盤面で、本人が1・2・3投目を選ぶ。射出間隔が解ける所でだけ時計を止める。
2. 加熱する方角をボタンで選び、回答と数字を出す。短いが、3投目までの履歴が身につかない。
3. 自由プレイ中に常時説明を重ねる。実戦には近いが、最初の解放まで長く、別方向との条件をそろえにくい。

1を選んだ。衛星のある途中盤面、履歴なしから始め、最初の2投は0、同じ右方向の3投目は2、反対なら0。どちらも実際の射出と同じlaunchHeatingで判定。狭い方角の帯は判定の変わる境目で分け、本体計算が加熱と返す区間だけを赤く示す。盤面の回転に運ばれた方角も含む。受理した履歴と実加算を残す。練習中も盤面を押して方角を選べる。

## 崩壊の3案

1. 一つの途中盤面で、衛星を作る→合体で力をためる→射出→発動を進め、条件が変わる所で止める。
2. 未解放・満タン・受付の静止画像を並べる。軽いが、力が増える因果を自分で追えない。
3. 完全な自由プレイから目標を探す。操作は共通だが、練習を終えるまでの時間と成功をそろえられない。

1を選んだ。教材用に用意した山であることを画面へ明記し、解放前から同じ計算を続ける。最初の衛星で力1、残る山の本物の合体で12となり、そこから盤面または同じボタンで一投できる。初回は射出後に停止、チェックを外すと本物の1.2秒受付。力や解放の値を表示側から書き換えない。合体の続きでも冷えるため、この準備教材の最終熱0を崩壊だけの成果と扱わず、実際に崩壊で減らせた値だけを表示する。危険な山での冷却見本は旧session設定と試験に残るが、新UIからの入口はまだない。

## 原因と配置

- 限界外判定が付いた天体だけに赤い輪。盤面直下へ加熱中・冷却中・停止中と原因を表示。成長警告と照準加熱もDOM文字で補助する。
- 「自然」の合算をやめ、限界外上昇と自然冷却を別々に蓄積。合体と崩壊も実差分のまま。
- ページと右欄の二重スクロールをやめ、ページ一つの流れへ。スマホ390×844で連投の3投目結果と再試行が画面内に収まることを親が視認。代表位置は盤面上端146.4、下端500.9、再試行664.8〜706.0px。実機のタッチを測った数ではない。
- 停止へ切り替わる最後のtickも再描画する。これがないと3投練習のボタンが前の無効表示に残ったため、実操作で見つけて修正。
