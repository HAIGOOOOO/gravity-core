# 本体で射出を続ける3分間の計測

`node src/dev/app-frame-probe.mjs 180 5175` を起動し、アプリ内ブラウザー1280×720で `http://127.0.0.1:5175/?seed=1` の「はじめる」を押す。本体のループに計測と0.5秒ごとの入力だけを読み込み時に追加。テーマ・演出・音・保存・同じプレイ中の処理は本体の既定値。ポートを分けて通常のプレイのローカル記録と分離した。アプリの製品ファイルは変更していない。

ゲーム終了後は同じシードで次のラウンドへ進む。本体のヒットストップやスローも含むので、実時間180秒はゲーム内180秒と一致しない。表示間隔はブラウザーのrAF間隔、更新と描画はコールバック中のJS経過時間。どちらも画面に実際のピクセルが表示された時刻を直接測る指標ではない。

| 実時間 / コマ | 最大天体数 | 更新＋描画JSの95%点 / 最大 | 表示間隔の中央値 / 95%点 / 最大 |
|---|---:|---:|---:|
| 描画変更前・初回 180.01秒、10,111コマ（プレイ中10,079）、2ラウンド | 43 | 2.60 / 23.40ms | 17.70 / 18.40 / 37.90ms |
| 描画変更前・処理別 180.01秒、10,094コマ（プレイ中10,062）、2ラウンド | 43 | 2.70 / 28.80ms | 17.80 / 18.50 / 35.40ms |
| 描画変更後・開始直後 15.01秒、850コマ（すべてプレイ中）、1ラウンド | 15 | 1.80 / 18.70ms | 17.60 / 18.20 / 18.70ms |
| 描画変更後 180.00秒、10,109コマ（プレイ中10,077）、2ラウンド | 43 | 2.60 / 16.90ms | 17.80 / 18.40 / 35.70ms |

表示間隔16.7ms超は初回10,109回、処理別10,093回、変更後の短時間849回。初回と短時間では同じPCで別のボット計測が動いた。処理別はボットを止めて測定。最も重いコマは開始後80刻み・2体で、更新1.00ms、盤面0.20ms、演出27.60ms、HUD 0.00ms。更新と描画の合計が16.7msを超えたのは3回。

天体の穴が外周の内側に収まる場合に切り抜きを一度にまとめ、描画しない時間帯の切り抜きと透明な発光を省いた。変更後の短時間計測で最も重いコマは69刻み・2体で、盤面15.00ms、演出1.50ms。変更後の3分では最も重いコマが79刻み・2体で、更新0.50ms、盤面0.30ms、演出16.10ms、HUD 0.00ms。更新と描画の合計が16.7msを超えたのは1回。3分の再計測の冒頭は別のボット計測の終盤と重なった。これは各回で合計が最大のコマの記録で、演出単独の最大や短縮の因果関係は未確定。表示間隔16.7ms超は10,108回で、表示間隔の基準は未達。
