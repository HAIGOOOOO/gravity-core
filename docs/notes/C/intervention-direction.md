# 射出後の一手（2026-10-22、題目000・1周目の続き）

## 3案
1. ゲージをため、撃った直後に崩壊を一度使う。山を締め、同じ天体を引き寄せ、熱を下げる。
2. 飛行中の天体をもう一度押して重力弾へ変える。一投との因果は強いが、動く小物を狙う操作が増える。
3. ミサイルで邪魔な一体を消す。Cosmic Collapse作者の紹介で効く救済だが、このゲームの熱・重力との結び付きは薄い。

1を選ぶ。既存の崩壊の試作を使い、連鎖でたまる力を危機の一手へ変える。2はタッチ時の狙い直し、3は既存作品と同じ消去という別の費用がある。

実物の参照はrules-cycle1.mdのThrees開発メール・スイカゲームぷらねっと・Cosmic Collapse作者ページを継続。新しい周へは進めていない。

## 本番の芯
最高Tier3で解放、連鎖数に応じた12点のゲージ。直前の成功した射出から1.2秒未満、一投につき一度。拒否された射出は窓を延ばさない。試作の握り・渦・井戸・重力弾は通常の計算では使えない。

入力は直前のLaunchInputにcollapseTickを残す。次の射出と同tickなら崩壊を先に再生する。通常の保存、プレイヤーの前後シーク、共有の文字列、途中盤面の復元を同じ入力列へ通す。崩壊の実冷却もtickごとに受け渡し、自然冷却として表示しない。
