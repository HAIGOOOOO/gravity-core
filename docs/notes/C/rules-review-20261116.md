# 題目000・1周目の初見審査と修正

独立した初見役がアプリ内ブラウザー390×844で、連鎖の一投と見返し、崩壊の解放から発動、成長、連投、敗因、自由プレイを操作した。実機タッチ・実聴はなし。比較対象は『スイカゲーム』。次の物、落下位置、結果を盤面の視線のまま追える点を参考にした。

| 重さ | 見つかった問題 | 今回の対応 |
|---|---|---|
| ★ | 見返しで合体ごとの冷却量が読めず、停止の案内まで限界外の赤になる | 盤面下にこの合体の冷却と同じ刻みの熱変化を表示。再生の案内は中立色 |
| ★ | 崩壊の力をためた後、一投する盤面が画面外に残る | 準備・射出と崩壊を盤面下へ。満タンの投入位置に金の輪を表示。画面上端で盤面が切れていれば戻す |
| ★ | 成長結果の凡例と結論が再生操作より下にあり、盤面と一緒に見られない | 盤面直下に予告と結果の内外、線の短い凡例 |
| 4 | 崩壊を待っている間に方角を選ぶよう案内される | 崩壊を押すと再開する案内に変更 |
| 5 | 合体のない結果でも「合体の瞬間へ戻せます」と出る | その記録にある操作だけを表示 |
| 6 | 崩壊後の冷却結果の前に衛星の図が残る | 結果では準備図を畳む |
| 7 | 3投目だけ比べるために前の2投もやり直す | 2投後の盤面を復元する「3投目をもう一度」 |
| 8 | 真上への案内が3箇所に重なる | 投げ方は盤面の金の輪にそろえる |
| 9 | 通常幅で熱と次の天体が重複する | 熱とメーターは盤面下、次の天体は各幅で1箇所 |
| 10 | 補助や計測まで同じ枠と色で、主操作が埋もれる | 崩壊の準備は盤面下と金色の枠で区別。他の練習の視覚的な順位は再審査 |

初見役が機械的に感じた点は同文反復、定型的な長文、同形のボタン、色の意味混在、情報の重複。別の審査役による修正後の確認はこれから。

親が390×844で確認。見返し第1合体は熱68.0→66.2（冷却−2.0、限界外＋0.2）・100点、第2合体は67.3→62.5（冷却−5.0、限界外＋0.2）・430点。成長は静止時の予告が限界外で、実際は限界内。盤面上端と凡例下端が各115・607px。崩壊の満タン時、補正後の盤面上端12px、ボタン下端483px。盤面の輪から直接一投し、崩壊−18.6、結果0.0。連投は右右右の最後＋2から2投後へ戻り、左で＋0。画像は [合体の熱](rules-contact-heat-20261116.png) と [崩壊の一投](rules-collapse-aim-20261116.png)。

本線の共有更新も統合。現行の指紋を持つ形式4で崩壊を保持し、旧Cの実物コードと端末保存を復元した。旧Cのコードは同じルールのとき3,310点を再現。本線の旧コードは入力を読めるが、異なるルールとして再生を止める。元の33投を現行ルールで再計算した10分の見本は [共有画面](share-sample-20261116.png) で7,630点を確認した。
