# 題目00・1周目（方針の版8、2026-10-19）

## 見た物

1. [Tetris Effect: Connected公式](https://tetriseffect.game/ja/) / Enhance。公式の背景プレイ映像を確認。暗い空間に盤面の輪郭と落下物を残し、周りの星の明るさと密度を変えている。ZONEは時間を溜めて解放する仕組み（公式説明）。このゲームでは、狙いと限界リングを固定したまま、外側の層が山場に反応する構成に使う。時間の具体値は本作の上限に従う。
2. [Balatro公式発売映像](https://www.youtube.com/watch?v=2n9pkiuSZLU) / Playstack、2024。公式サイト内の映像を再生して観察。加点と倍率の青・赤の数値が別々に発火し、炎と大きな数字で計算の山場を作る。単に全画面へ粒をまかず、数字の位置へ視線を運ぶ。本作では得点が合体地点から届く軌道と、到着時の反動をつなげる。
3. [Peggle 2公式発売映像](https://www.youtube.com/watch?v=RvnEOQVc0l8) / Xbox、2014。25秒付近の複数盤面と、横へ伸びる得点バー・大きな数字の場面を確認。盤面の細かい物と、得点の強い図形を別の場所に置き、結果を読む場所へ視線を運ぶ。細かい命中のコマ数やExtreme Feverの全過程は測定できていない。素材・画像・音源は流用しない。

## 方向の異なる3案

- A「重力の鋳造」: 内向きの吸引と圧縮を短く置き、外への破片・曲がる尾・軌道の残光へ。数字も同じ重力の曲線を通って情報欄へ飛ぶ。連鎖は局所→接続→空間→反転→解放と広がる。
- B「断層」: 一方向のせん断で輪郭を割り、斜めの面・亀裂・欠片・押し返す反動を中心にする。連鎖が進むほど割れ目の方向が次の合体へ伝わる。
- C「恒星の点火」: 天体の模様が内側から発火し、光の膜とコロナが段ごとに増える。最大連鎖では光源そのものを切り替え、静かな残光で締める。

Aを選ぶ。核へ向かう運動と、2つが1つになる圧縮を、本作のルールと同じ意味で使える。Bの方向性は破片へ、Cの面の光は誕生の一瞬へ限定して取り入れる。同じ図形を色だけ変えた3案にはしない。

## 1周目の範囲

本番のEffectsLayerへ接続する多層の土台と連鎖の段差を作る。固定数の出来事枠、事前描画した光、seedによる形の微差、時間の依頼、動きを減らす代替、リセットを共通にする。層の一覧はコードの表とprogressの番号を一致させる。動画・1コマごとの図・描画時間を同じ見本から出す。基準へ届くまで最低3周し、1周で提出とはしない。
