## 違う3案

- A「圧縮して殻を割る」: 段が上がるほど圧縮の時間を伸ばす。解放の瞬間に厚い殻が外へ分かれ、遅い波が周囲と外周に届く。中央には新しい天体を残す。
- B「打点を順に刻む」: 毎段の合体は短くし、5段目で過去の合体位置へ順に反応を戻し、最後の数値へ集める。局所の連打を主役にする。
- C「軌道を巻いて解く」: 破片を外へ飛ばさず、核のまわりを一周する大きい帯へまとめ、5段目で帯を一度ほどく。長い連続運動を主役にする。

Aを選択。1周目は細い線と局所の光へ寄り、段の上がりが同時発光の差に留まった。圧縮時間と太い殻、結果を見せる空洞を主役にすれば、文字を消しても段差を作れる。Bは実際の連鎖列の見本と一緒に次に検討、Cは照準との区別が弱いため今回は選ばない。
