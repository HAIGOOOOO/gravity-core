# 4方向の繰り返しと、通常の合体狙い

再生形式13。候補は計測時だけ仕組みを置き換える。従来の直近8投による追加熱＋9は、seed1708の合体狙いの401投目にも入った。

1. 方角ごとに3投を確認する。直近12投の全体を4組に分け、24度の幅に3投ずつ収まれば＋9。
2. 直角にずれた帯を4つ置く。直近16投のうち幅30度の帯に各3投以上、合計13投以上収まり、次の射出もどれかの帯に入れば＋9。途中の最大3投が帯から外れても判定できる。
3. 直近8投を分ける既存の試作。24度の組に2投ずつで＋9。開始時の追従は速く、同じ方角が偶然揃った場合にも反応する。

## 1701〜1708で選択

## 1801〜1816で確認

別の16シード、現行・16投の案とも各160走。2走ずつの合体狙いは5分で打ち切り、打ち切り時の得点を含む。表は同じ間隔のランダムに対する得点中央値比。

ランダム2条件と合体狙いは各16シードで得点と終了時刻が一致。6投ごとに別方角では加熱中央値202→1,023に対し、時間119.81→117.58秒、得点281,565→276,825。間隔0.67〜0.82秒も差は小さい。追加熱の実装は試作。致命的な射出の予告修正前のボット値なので、通常の合体狙いは新しい照準でも再確認する。
