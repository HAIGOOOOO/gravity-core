# 初見審査：GRAVITY CORE ルール画面

対象： http://127.0.0.1:5173/dev/rules.html
審査日：2026-10-27

通常幅（1265×712）と390×844で、連鎖・崩壊・成長・連投・敗因・自由プレイを実際に操作した。通常幅は連投を右→右→右、スマホ幅は右→右→左で比較。敗因は限界外・連投の両方、自由プレイはクリック投射・引いて離す投射を両方試した。崩壊は衛星解放から蓄力・射出・発動・結果まで確認した。

判断材料は画面と操作のみ。作り手の説明・ソース・過去審査は読んでいない。音は未確認（実聴できていない）。途中に開発側のファイル更新による再読込みが1回あり、そのリセットは欠点に数えていない。影響したスマホ幅の崩壊は再確認済み。コード変更なし。viewportはresetし、自分の専用タブだけcloseした。

## 欠点10個：重い順

★は、初めて人に見せる前に直す必要があるもの。

### 1. ★ 練習を終えても、実際の投げ方を練習できていない
どこが：連鎖は「真上から一投する」、崩壊は段階別ボタン、連投は「右から／左から」で進み、自由プレイになって初めて「押して離す／引いて離す」が出る。
なぜ駄目か：練習で覚えたのはボタンを押す順番で、盤面上で狙いを作り、放し、結果を修正する操作へ学びがつながらない。
どう直すか：最初から本番と同じ盤面操作を使わせ、狙う場所・押す位置・引く方向を一段階ずつ案内し、本人の一投で課題達成を判定する。

### 2. ★ 合体を理解するための盤面が、演出で読めなくなる
どこが：崩壊中や複数合体で、強い白青の発光、放射線、周回線、得点、次の連鎖予告が中央の天体に重なる。
なぜ駄目か：どの2個が接触して何に変わったかが隠れ、連鎖の因果を学ぶ画面なのに、結果の派手さしか追えない。
どう直すか：現在合体する2個だけを先に強調し、発光を天体の背面へ抑え、得点と予告を盤面外へ分け、接触ごとに止めて見返せるようにする。

### 3. ★ 天体の成長順と「衛星」の意味を画面から覚えられない
どこが：盤面の天体に名前がなく、成長順の一覧もない一方で、崩壊・自由プレイは「まず衛星を作る」「力0/12」を前提にしている。
なぜ駄目か：どの見た目が衛星で、何を合体させれば作れて、核とはどう違うかを初見で結びつけられず、崩壊解放への目標を立てられない。
どう直すか：核を別の造形にし、常時見られる成長順の図へ名称と解放条件を添え、いま必要な天体と到達先を盤面・一覧の両方で示す。

### 4. 番号順の「次へ」が5番の敗因を飛ばす
どこが：4.連投の結果で「次へ」を押すと、通常幅・スマホ幅とも5.敗因を通らず自由プレイへ移る。敗因内で「連投の加熱」を選ぶと上部の5番の選択表示も外れる。
なぜ駄目か：並んだ番号と実際の進行が違い、終了条件を確認しないまま練習完了と思いやすく、いまいる練習も分かりにくい。
どう直すか：1→2→3→4→5→自由プレイに進行をそろえ、敗因のどちらの小項目でも5番の選択状態を維持する。

### 5. 教えたい熱の増減と、大きく出る熱量の動きが食い違う
どこが：連鎖は70→65なのに結果文は「合体で熱−7」、連投は加熱を試しても40→28／26になり、限界外加熱・自然冷却の内訳は折りたたみの中にある。
なぜ駄目か：計算自体は内訳で説明できても、初見で目立つ数字だけ追うと「連鎖の冷却量が合わない」「連投しても冷える」と受け取り、主題が弱まる。
どう直すか：結果のすぐ横に開始→加熱→合体→自然冷却→最終を短い収支で出し、連投の比較課題では自然冷却を同条件で固定して差分を主表示にする。

### 6. スマホで必要な盤面内の文字まで縮小される
どこが：390×844では、成長の赤い警告、天体に重なる連鎖予告、加熱予告が小さくなり、次の天体も小さい文字列になる。
なぜ駄目か：盤面を見ながら読み取るべき情報ほど判読しづらく、色や形の小さな違いと併せて視線を止める負担が増える。
どう直すか：盤面の縮尺とは別に文字の最小サイズを保ち、警告・次の天体・連鎖予告を固定サイズのHUDへ移し、天体は図と名前で見せる。

### 7. 成長の比較が、画面のどこを測った数値か分からない
どこが：成長結果は灰点線・赤破線・青線を重ね、「予告320／実際216／限界320」「中心寄りへ103」と説明するが、測定点や距離の単位が盤面に示されない。
なぜ駄目か：重なった円と線を文章の数字へ対応させる作業が必要で、「この向きへ投げるとどこが危険か」という判断に変換しづらい。
どう直すか：予告位置・実際位置・限界の対応箇所を番号付きで指し、同じ基準からの距離を線で示し、別方向ならどう変わるかを隣で試せる課題にする。

### 8. 敗因の練習が、ほぼ確定した失敗を眺めるだけになっている
どこが：敗因は熱99の盤面から1操作で100になり、理由の文章と「もう一度／次へ」が出る。
なぜ駄目か：死因の名称は分かっても、一手前にどの兆候を見て何を変えれば助かったかを自分の操作で確かめられない。
どう直すか：終了後に「一手前へ戻す」を出し、限界外の山を崩す・方角を変えるなどの回避を実行して、失敗結果と救済結果を比較させる。

### 9. 敗北と成功が同じ色・調子で表示される
どこが：敗因の「熱量100で終了。」が、連鎖成功や崩壊成功と同じ明るい緑の見出しで出て、状態表示も緑になる箇所がある。
なぜ駄目か：本文を読む前の一瞥で成功・危険・終了を区別できず、熱量100という重大な状態が通常の課題完了と同じ重さになる。
どう直すか：成功・警告・敗北に色だけでなくアイコンと見出しの型を割り当て、敗北には原因箇所の強調と次の回避行動を一組で出す。

### 10. 投げられない時間の反応が、投げる場所に出ない
どこが：自由プレイで続けて押すと一投が受け付けられず、「次の一投まで0.3秒」「少し待って、もう一度」が盤面下の説明側へ出る。
なぜ駄目か：指や視線は盤面にあるため、投げたつもりなのに出ない理由を別の場所へ探しに行く必要があり、操作が不安定に感じる。
どう直すか：射出位置に受付待ちの円形ゲージを出し、入力を受け付けた瞬間を形と動きで返し、待ち時間中の入力は直後の一投として予約できるようにする。

## AIが作った物に見えるか

画面と動きだけなら、AIが作った試作物に見える。そう感じさせた所を、印象への寄与が大きい順に挙げる。

1. どこが：合体・崩壊に重なる発光、輪、放射線、三角片、周回線。なぜそう見えるか：効果を足した量に対して、何を見せるかという整理が弱く、汎用の派手な演出を積み重ねた印象になる。
2. どこが：練習タブ、射出、次へ、自由プレイ、計測が似た枠付き長方形で並ぶ。なぜそう見えるか：用途の違う操作が同じ部品で処理され、遊びの優先順位より実装した機能一覧が前に出ている。
3. どこが：「中心寄りへ103」「180コマ計測」や小数付きの収支がそのまま出る説明。なぜそう見えるか：プレイヤーの判断を助ける言葉への編集が薄く、内部の状態を説明文へ直結したように見える。
4. どこが：単純な円・縞・クレーターで描いた天体と、密な光学風エフェクトの組み合わせ。なぜそう見えるか：天体の質感や重さと演出の密度に差があり、別々の定番表現を寄せた印象になる。
5. どこが：4番から5番を飛ばす進行、敗因の小項目で外れる選択表示、緑の敗北見出し。なぜそう見えるか：個々の状態は作ってあっても、一続きの体験として通して調整した跡が弱く見える。

比較作品は『ぷよぷよテトリス２』。連鎖を覚える教材として比べると、こちらは「見た」から「自分の操作で再現できた」へ進む課題が足りない。
