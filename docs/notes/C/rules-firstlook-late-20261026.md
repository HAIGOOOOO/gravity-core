# ルール画面・初見審査（2026-10-26）

作り手の説明・過去の審査・ソースは読まず、専用タブで現在の画面だけを実操作。通常幅（既定）とスマホ幅（390×844指定）を確認。
確認済み: 連鎖の一投と2連鎖結果／崩壊の受付時間切れと受付内成功／成長の発射前後／連投の同方角＋14.0と反対方向＋0.0／自由プレイのクリック投下とドラッグ。
音: 実聴できないため未確認。音ありのチェックボックスの存在だけを確認した。
★は、人に見せる前に直すべきもの。重い順。

1. ★ 連鎖成功の教材が、熱を逃がせた実感を逆転させる
どこが: 初期70.0から2連鎖成功後79.5へ上がる一方、成功文は「合体冷却の合計 −7.0」を強調する。
なぜ駄目か: 「連鎖で、熱を逃がす」という最初の約束に対し、初心者の見える最終結果は加熱であり、正解行動に確信を持てない。
どう直すか: まず連鎖で総熱が下がる例を体験させ、危険な途中盤面の例は別段階で「撃たなければ何度だったか」と並べる。

2. ★ 練習の崩壊入力と自由プレイの入力がつながらない
どこが: 崩壊練習は「一投する」と同じボタンをもう一度押すが、自由プレイは盤面で撃ち、右側の別ボタン「崩壊 0/12」を使う構成。
なぜ駄目か: 練習で覚えた手の動きを本番へ移せず、1.2秒の受付中に視線と指を別の場所へ移す必要が生じる。
どう直すか: 自由プレイと同じ盤面操作・同じ位置の崩壊ボタンで練習させ、最初だけ受付を長くして段階的に1.2秒へ縮める。

3. ★ スマホHUDが、成長の警告を覆う
どこが: 成長の盤面上部にある「成長後、限界を越す可能性」が、固定の「熱／次」HUDの背後に隠れる。
なぜ駄目か: この練習で一番知らせるべき危険情報が、標準的な縦長画面で読めない。
どう直すか: HUD用の領域を盤面の外に確保し、警告は照準近くか操作ボタン直上に表示する。

4. 通常幅でも、結果が熱ゲージと内訳を下へ押し出す
どこが: 右側だけに内側スクロールがあり、連鎖成功後は79.5の下や加熱内訳が画面下へ消える。ページ全体にも別のスクロールがある。
なぜ駄目か: 成功文・最終熱・加熱理由を一度に照合できず、「−7.0」と「79.5」の食い違いを理解する負担が大きい。
どう直すか: 現在熱と開始差分を常時見える結果カードへまとめ、右ペイン独立スクロールを減らす。

5. 成長予告の線が、図だけでは読み分けにくい
どこが: 元の位置・予告・実際の移動が細い灰点線・赤破線・青線で重なり、凡例と距離320／216／320の説明は盤面から離れた下にある。
なぜ駄目か: どの天体のどの外縁が危険なのかを照合作業で理解する必要があり、初見では線が多い図として残る。
どう直すか: 対象天体と外縁だけを太く強調し、「予告」「実際」を線のそばに直接付け、前後を短く切り替えて見せる。

6. 赤い限界線と熱100の意味を、最初に結び付けていない
どこが: 初期盤面には赤い破線と熱70.0／100が出るが、線を越えると何が起き、100でどうなるかが最初の操作付近には示されない。
なぜ駄目か: 合体操作を実行できても、何を避けるゲームなのかを自分の言葉で説明できないまま進めてしまう。
どう直すか: 最初に「線の外に出ると加熱／熱100で終了」を短く示し、線外の天体と増える熱を同時に指す。

7. 連投練習が、答え付きの二択にとどまる
どこが: ボタンに最初から「同じ方角へ（熱＋14.0）」「反対の方角へ（熱＋0.0）」と答えが書かれ、用意された一投だけで終わる。
なぜ駄目か: 「3投目から」「盤面の流れを追いかけても同じ」という判定を自分で作って確かめられず、実戦での方角の選び方が身に付きにくい。
どう直すか: 初回の比較後に、直近の投射方角を見ながら自分で3投する小課題を置き、結果の加熱だけを後から返す。

8. 天体の名前と成長順を盤面から追えない
どこが: 次の天体には小粒子・隕石などの名前がある一方、盤面の縞模様や紫の天体には名前がなく、自由プレイでは「衛星を作ると解放」とだけ出る。
なぜ駄目か: どれが衛星で、何を合体させるとそこに達するのかを、絵と用語の対応から判断できない。
どう直すか: 常時参照できる短い成長順の図を用意し、今必要な組み合わせと衛星を強調する。

9. 練習の終了状態が、操作不能のボタンとして残る
どこが: 成功後も「真上から一投する」や「この照準で撃つ」が暗い無効ボタンとして残り、再開も無効で、別の場所にもう一度／次へが増える。
なぜ駄目か: 視線の中心に古い操作が残り、新しく何をすべきかが状態変化よりボタンの増殖で伝わる。
どう直すか: 実行ボタン領域をそのまま結果と次へに置き換え、完了した段階には明確な完了表示を付ける。

10. 初心者向け補足と開発用の計測が同居する
どこが: 「冷却見本・内訳・計測」の中に、単発／3連鎖目／5連鎖目、熱の会計式、イベント列、「180コマ計測」が並ぶ。
なぜ駄目か: ルール理解に必要な説明と作者向けの検査が混ざり、何を読むべきかの優先順位が崩れる。
どう直すか: ルール画面では冷却比較と簡潔な理由だけを見せ、フレーム計測やイベントログは別の開発用画面へ移す。

比較作品: 『スイカゲーム』。
足りないのは、同種の物が触れて大きくなる因果を、絵の変化と一貫した成長順だけで理解できる明快さ。
