# 同じ共有コードの得点をNodeとブラウザーで照合

通常開始、seed 1、0.5秒ごとの直投げ187投を同じ共有コードで再計算した。旧計算では11,161刻みでNode242,150点・56体、アプリ内ブラウザー253,590点・47体。初めの240刻み、以降120刻みごとと終点を照合した範囲では、最初に盤面が違ったのは2,040刻み、得点が違ったのは7,080刻み。両環境で `Math.cos(0.1)` が0.9950041652780257と0.9950041652780258になる実測差があった。

新ルールは射出位置、盤面回転、照準の方向と加熱の角度差を同じ算術で計算する。三角関数は四分円まで縮め、固定係数の多項式を使う。形式13の圧縮入力を読み戻す際も同じ式から速度を復元する。旧形式12は当時の三角関数で再計算する経路を持ち、角度計算を混ぜずに途中状態からも復元する。旧形式の共有には実行環境差の案内を表示する。別ルール指紋は引き続き弾く。

| 記録 | 比較した地点 | 共通の最終得点 | 盤面の指紋 |
|---|---:|---:|---|
| seed 1、直投げ187投、11,161刻み | 333 | 290,200 | a06aed64 |
| seed 42、曲げ投げ202投、崩壊14回、13,468刻み | 352 | 342,670 | a4475198 |

両方とも各地点の盤面指紋、得点、天体数がNodeとアプリ内ブラウザーで一致した。曲げ投げは乱数seed 2027、67刻みごと、直投げの速度へ接線速度±120を加え、崩壊が受け付けられた時に使った。通常の共有画面でも [202投の結果](share-stable-replay-20261116.png) を確認。187投の終点と共有往復は回帰試験にした。

旧Cの崩壊入り実データ22投は旧コードと端末保存の両方から復元し、Nodeと同じブラウザーで3,310点だった。Nodeで旧版の途中シークも検証。長い旧コードには従来の実行環境差が残り、広いブラウザーやCPUでの形式13の比較は未確認。
