# 担当C　30秒の原稿（中間発表 11/20）

担当Cは、遊んだ時の手応えを担当しています。合体と連鎖の演出は本体に入っていて、合体の瞬間に光の輪と火花が広がり、ヒットストップと画面の揺れ、スローで「つながった」感じを出しています。持ち主から「今の5倍派手に」と言われ、合体の粒の数を5倍にし、火花を長い線に、衝撃波を太さの違う何重もの輪にしました。音は「おもちゃっぽい」と言われたので、楽器の音で作り直しています。次は、点の格子の見た目に合わせて演出を作り直します。

- 見せる物: 0秒から merge.webm（合体・3秒）、15秒から chain.webm（実際の計算の5連鎖・7秒）
- 動画は本体の自動撮影（scripts/capture.mjs が作る effects.webm・chain.webm）から盤面だけを切り出した物
