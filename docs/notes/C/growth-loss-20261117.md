# 合体直後に限界を越えるケースの比較

本番の物理と、成長の接触で増えた外向きの速度だけを引く処理を無効にした版を比較した。接触の位置補正、接線方向、回転、加熱などは共通。無効版は計測時だけViteで式を切り替える。

## 同じ盤面からの短い比較

既存の `contacts.test.ts` の配置を使用。熱99.9から、Tier 4の2体を `(82, ±41)`、Tier 3を `(155, 0)` に置き、いちばん外側のTier 6（ID 4）だけ動かした。天体の外縁を限界リングの内側2〜14論理px（2刻み）、角度を0.06〜0.18rad（0.02刻み）に置き、49盤面を3秒か終了まで追った。各天体は猶予時間を過ぎた状態から始めた。

| ID 4の計測 | 現行 | 外向き速度補正なし |
|---|---:|---:|
| 限界の外に出た盤面 | 4 / 49 | 45 / 49 |
| 限界外の敗因がID 4だった盤面 | 0 / 49 | 41 / 49 |
| 全盤面で最大の外向き速度（論理px/秒） | 19.85 | 967.55 |

[各盤面の計測値](growth-loss-fixtures-20261117.json)。

## 通常の初期盤面からのボット

2201〜2212、9戦法で各108走。5分の打ち切りなし。現行は限界外86件・連投22件、補正なしは限界外80件・連投28件。ここでの「限界外」は終点での敗因全体なので、接触直後の飛び出しかは区別できない。

0.5秒ごとのランダムは現行318,095点・110.2秒、補正なし341,225点・112.8秒。1秒ごとに固定する戦法は現行265,665点・196.6秒、補正なし92,495点・101.1秒。成長の補正が通常の射出戦法にも与える差として記録する。[現行](strategy-production-2201-12.json)・[補正なし](strategy-uncapped-growth-2201-12.json)。

ボットは `node src/dev/strategy-holdout.mjs 2201 12 <production|uncapped-growth> standard` で再実行できる。
