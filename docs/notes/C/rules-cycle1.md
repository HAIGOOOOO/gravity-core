# 題目000・1周目（2026-10-21、方針9）

演出の題目00・2周目は178325dへ保存済み。先に 2→4→5→1→3→6→7 の順で芯を変える。

## 実物から調べたこと
- [Threes開発者のメール公開](https://asherv.com/threes/threemails/): 2013-12の議論では、角への固定戦法は報酬追加だけでは崩れないと指摘され、動かない手で新しい札を出さない案を実装して試している。袋は固定組を引き切って補充する説明がある。運の偏りと戦法の穴は別々に測る。
- [スイカゲームぷらねっと公式](https://suikagame.jp/planet/)、[任天堂公式紹介映像](https://www.youtube.com/watch?v=51w_Eyf1vKM): 円形の盤面への落下と連続合体。円形だけでは差にならない。次の手に役立つ冷却と介入を、合体の結果として残す。（映像紹介の確認であり実機の試遊ではない。）
- [Cosmic Collapse作者の紹介](https://johanpeitz.itch.io/cosmic-collapse): 小さい天体で大きい天体を押し、順番を作って連続合体し、得たミサイルを窮地で使う。介入は常時使える操作より、使いどころを選ぶ一手として用意する。

## 熱量の3案
1. 合体した瞬間に冷やす。連鎖で2/5/8/11/14。イベントの実際の差分を画面へ渡す。
2. 合体で限界猶予を延ばす。物理由来の理不尽は減るが、熱が直接下がらず、冷却の判断が見えにくい。
3. 連鎖後に一定時間冷却を強める。積み重ねの達成感はあるが、合体と熱量変化の時間が離れる。

1を選ぶ。連鎖3の8点は危険時の約0.36秒分を取り戻す。連鎖5の14点も上限100に対して14%に抑え、超新星40との差を残す。最初は仮値。ボットで長時間化・偏りを測る。0未満へ冷やしたと扱わず、実際の差分をイベントへ入れる。

## 測定の範囲
`node src/dev/rules-bench.mjs <label>`で同じ8シード×固定/4方向/ランダム/螺旋、各最大5分を比較する。`overflowNearGrowth`は合体から成長時間内の限界越え開始の回数で、原因を断定する値ではない。弾き出しの因果は別の局所試験で確認する。結果はrules-*.jsonへ保存する。
