# 4方向を繰り返す間隔と順番の比較

本体のVite読み込み時だけ加熱判定を差し替え、本体のコードでは採用していない。各走は5分まで。同じ戦法、シード、受け付けた投数には同じ射出間隔の乱数列を使う。0.50〜0.65秒の間隔を基本とし、開始角は45度ずらす。盤面を読む対照には、予測で合体しやすい射出や安全な着地点を選ぶ既存のボットを使った。

## 1301〜1316、順番が同じときだけ＋8

| 戦法 | 現行の得点中央値比 | ＋8の得点中央値比 |
|---|---:|---:|
| 4方向 | 1.098 | 0.811 |
| 4方向、±2度 | 1.074 | 0.942 |
| 4方向、±2度、2周目の後半2投を入れ替え | 1.010 | 1.010 |
| 合体を狙う | 2.263 | 2.263 |

順番を入れ替えた4方向、ランダム、合体を狙う方は、全シードで成績が変わらなかった。合体狙いの1走（1305）は打ち切り。比はランダムとの得点中央値比。個別の95%区間は結果のJSONにある。

## 1401〜1416、4方角に各2投あるときに追加熱

直近8投を、互いに30度より離れた4組に分ける。組の幅は15度以内で、今回の射出が一組の両方から15度以内なら同じ方角とする。順番は問わない。8投分の経過が平均0.67秒以下のときに追加熱を入れる。

| 戦法 | 現行 | 追加＋8 | 追加＋12 |
|---|---:|---:|---:|
| 4方向 | 1.126 | 0.966 | 0.067 |
| 4方向、±2度 | 1.012 | 0.831 | 0.052 |
| ±2度、2周目で順番交換 | 1.025 | 0.809 | 0.074 |
| ±10度、2周目で順番交換 | 1.203 | 0.946 | 未計測 |
| 0.67〜0.82秒、±2度、順番交換 | 1.028 | 1.028 | 未計測 |
| 合体を狙う | 3.217 | 3.217 | 3.217 |

＋8は順番交換でも得点中央値を下げた。4方向の95%区間は0.694〜1.114、順番交換は0.562〜1.149。0.67〜0.82秒の4方向は、同じ間隔のランダムと比較してほぼ互角。間隔を少し空けた場合に効果はなかった。＋12は最速に近い4方向を中央値27〜28秒で終わらせ、変化が急だった。ランダムと合体狙いの成績は今回の3条件で同じ。合体狙いは各条件2走が打ち切り、表は打ち切り時点の得点を含む。手動で狙う場合の負担、照準の説明、別の角度と間隔への有効性は未確認。

記録は [1301現行](strategy-production-aiming-1301-16.json)、[1301順番＋8](strategy-cycle8-aiming-1301-16.json)、[1401現行](strategy-production-evasion-1401-16.json)、[1401方角＋8](strategy-zones8-evasion-1401-16.json)、[1401方角＋12](strategy-zones12-aiming-1401-16.json)。再現は `node src/dev/strategy-holdout.mjs <開始シード> 16 <実験名> <aiming|evasion>`。

## 1501〜1516、間隔の条件を外して＋10

4方角に各2投ある判定を使い、時間条件を外した。0.50〜0.65秒のまま4方角に撃つと、得点中央値比は1.091→0.206、終了は127.6→50.5秒。順番交換は1.073→0.317、±10度のぶれも加えると0.892→0.819。0.67〜0.82秒では0.929→0.921で大差なし。ランダムと合体狙いの全シードは同じ結果、各128走の打ち切り0。ゆっくり撃つ場合にはルール自身の冷却が増え、別の時間境界が不要な可能性がある。最速を大きく罰する調整で、プレイヤーが短時間に4方角を試すことへの負担は未確認。
