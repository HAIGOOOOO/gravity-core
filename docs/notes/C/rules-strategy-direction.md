# 題目000・6番の比較（2026-10-22、1周目の続き）

実物の調査はrules-cycle1.mdのThrees開発者、スイカゲームぷらねっと公式、Cosmic Collapse作者の紹介を継続する。特にThreesの固定戦法への対処と、単なる報酬追加では穴が残るという記録を、今回の比較へ使う。K1K2の数値は参考に留め、自分の同じ種で測る。

## 向きの違う3案
1. **繰り返した方角に熱を足す。** 最高Tier3以降、直前8投で±15度以内だった数×4の熱。固定と4方向の繰り返しに直接効くが、入口で自然に同じ場所へ撃つ人も罰し得る。
2. **山がゆっくり流れる。** 毎秒12度の回転で、画面の同じ場所と山の同じ場所が一致し続けることを防ぐ。物理と照準の一貫性、周囲の読みやすさが必要。
3. **接触時の減衰だけを変える。** 5→1.5で、山を同じ場所へ固定しにくくする。操作を増やさないが、弾き出しが増えないか別に見る必要。

比較用コードはstrategy-probe.mjs。本番のSimulationは書き換えず、複製を一時ファイルへ作り、終了時に消す。最初は同じ1〜4の4シード、各5分上限、固定・4方向・ランダム・螺旋。結果はstrategy-screen.json。候補を選んでから、選択に使わなかった種で確認する。4シードだけで穴を塞げたとは扱わない。

熱案では固定の中央値が2220点・6.75秒で終わった。序盤を極端に短くするため、そのまま採用しない。最初の4シードの変更前は固定457490・4方向367965・ランダム259435・螺旋349540。これは以前の8シードの中央値と同じ数ではなく、比較の標本数が違う。

## 選択
盤面全体を毎秒12度回す案を選ぶ。静止した座標系で予測してから、同じ流れで道すじを回せるため、着地した山だけを回すより照準と整合を保てる。全体12度は固定316255/4方向275275/ランダム308690/螺旋244630で固定比1.024。18度も比0.880だったが、より遅い12度で初期の基準1.1以内になったため、これ以上速くしない。

ここで12度を固定し、選択に使わなかった101〜116の16シードで変更前と比較する。結果を見て値を変えた場合、この16シードを未使用の検証と呼ばない。固定方角・速度違いの試験も別に残す。まだ採用後の基準達成を断定しない。
