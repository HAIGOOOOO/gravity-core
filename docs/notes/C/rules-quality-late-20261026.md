# rules.html 品質審査（2026-10-26）

対象: http://127.0.0.1:5173/dev/rules.html

作り手の説明、過去審査、ソースは読まず、専用の in-app browser タブで実操作した。通常幅（約1265×712）とスマホ幅390×844で、連鎖・崩壊・成長・連投・敗因・自由プレイを確認。連鎖・崩壊・成長は通常幅で結果まで確認し、スマホ幅でも射出・発動を操作。連投は同方向／反対方向、敗因は限界外／連投を通常幅で比較。スマホ幅では同方向連投と限界外敗北を結果まで確認。自由プレイは両幅でクリック射出とドラッグ投げを操作した。音スイッチの切替は確認したが、音は実聴できず未確認。

以下は重い順。★は、ゲーム内のルール説明として人に見せる前に直すべきもの。

1. ★盤面と操作の分離が、スマホで学習を阻害する。
   - どこが: 390×844ではヘッダー・盤面・小型HUDで上から約470pxを使い、その下の説明・操作欄だけが別にスクロールする。通常幅にもページと説明欄の二重スクロールがある。
   - なぜ駄目か: 盤面を見ながら説明、発動ボタン、結果を一緒に把握できず、時間制限のある操作まで視線とスクロールの往復になる。
   - どう直すか: 練習中の操作と短い一文を盤面直下の固定領域に集約し、詳細説明は任意に開く。スマホでは課題を一画面で完結させる。

2. ★加熱した理由が、動いている最中に読み取れない。
   - どこが: 限界外の山の敗因練習は99から始めても最初は96台へ下がり、その後100で終了する。通常表示の内訳はこれを「自然に」の増減へまとめている。
   - なぜ駄目か: 「何を放置すると負けるか」の練習なのに、冷却から加熱へ変わる理由と発生源を、終了後の文章で理解することになる。
   - どう直すか: 猶予の残りと限界外の対象を盤面上で結び、加熱開始の瞬間に対象から熱ゲージへ同じ色の反応を出す。「自然」は冷却と限界外加熱へ分ける。

3. ★連投練習が、実際の操作で避ける知識を教えていない。
   - どこが: 「同じ方角へ（熱＋14.0）」「反対の方角へ（熱＋0.0）」の既製ボタンを一度押すと、ほぼ即座に結果と再試行へ切り替わる。
   - なぜ駄目か: 3投目から加熱するという説明に対して、その前の2投・狭い方角の範囲・回る盤面との関係を自分で試せない。正解ラベルを読む課題になっている。
   - どう直すか: 1投目から本人に狙わせ、連投履歴と危険な扇形を盤面に残す。3投目の直前に同方向と別方向を選び、同じ時間軸で比較できるようにする。

4. ★崩壊の練習から自由プレイへの条件の落差が大きい。
   - どこが: 練習では一投直後に「崩壊を使う」を押せるが、自由プレイでは最初から「崩壊0/12」が無効で、「衛星を作ると解放。合体で力をためます。」だけが出る。
   - なぜ駄目か: 覚えた操作をすぐ再現できず、衛星がどの見た目なのか、解放と12までの蓄積のどちらが足りないのかもその場で判別しにくい。
   - どう直すか: 練習の中で解放・蓄積・射出後受付を一続きに体験させる。自由プレイの無効ボタンには不足条件を一つずつ明示し、対象の天体も図示する。

5. 成長予告が、次の狙い方の判断に結びついていない。
   - どこが: 成長前は「限界を越す可能性」と赤破線が出るが、結果は予告320／実際216／限界320で内側に残り、「山が中心寄りへ103動いた」と文章で説明する。
   - なぜ駄目か: 大きく外れた予告を見せてから注意書きで補うため、次回どの程度の余裕を取ればよいかが分からない。
   - どう直すか: 成長の大きさと山の移動を順に再生し、移動前後の輪郭を一度に重ねすぎない。安全な方向と危険な方向を本人が選んで比較できる課題にする。

6. 盤面内の重要文字がスマホで小さすぎる。
   - どこが: 390px幅の成長画面上部の警告、連投画面の方角・加熱注記が、縮小された盤面と一緒に極小表示される。
   - なぜ駄目か: 読むべき判断材料が最も読めず、下の大きな説明文だけに依存する。狙う対象と注記も重なって見える。
   - どう直すか: 注記を盤面の縮尺から切り離し、スマホ用の最小文字サイズと短い吹き出しを使う。重なる説明は対象の外へ逃がす。

7. 成功結果の数字が競合し、何が起きたか一目で通らない。
   - どこが: 連鎖成功時に「合体直前67.3→直後62.3（−5.0）」「合計−7.0」「現在65.4」「自然に＋2.4」、得点・回数・連鎖数が別々に並ぶ。
   - なぜ駄目か: 主役である2連鎖の冷却を、複数の差分と時点の違う数字から頭の中で再構成しなければならない。
   - どう直すか: 成功時は2連鎖と総冷却だけを大きく示し、熱ゲージ上に今回の変化を残す。単発内訳や会計式は詳細へ移す。

8. 射出できない入力への返答が弱い。
   - どこが: 自由プレイで同じ場所を続けてクリックすると、2回目はキューも説明も変わらない場面がある。画面上に「待機中」「次の一投まで」などの反応が出ない。
   - なぜ駄目か: 射出間隔による抑制なのか、狙い位置が無効なのか、入力が落ちたのかをプレイヤーが区別できない。
   - どう直すか: 次弾が準備中なら盤面とキューで短い待ち表示を出し、入力時にもその理由を返す。射出可能になった瞬間を小さく明示する。

9. 動きの比較に必要な再生操作がない。
   - どこが: 連鎖・崩壊・成長は結果で時間が止まり「再開」は無効になる。用意されるのは「もう一度」「次へ」と、成長の重ね表示だけ。
   - なぜ駄目か: 見逃した合体順や山の移動を、自分の速度で追い直せない。再試行すると結果から初期状態へ戻り、同じ瞬間を対比しにくい。
   - どう直すか: 結果に短いリプレイと低速再生を置き、成長前・合体直後・移動後の3地点だけでも行き来できるようにする。

10. 操作・状態・結果の見た目に優先順位がない。
   - どこが: 練習選択、自由プレイ、一時停止、射出、再試行が似た緑灰色の長方形で並び、成功文・説明文・計測情報も近い調子の文字で積まれる。
   - なぜ駄目か: 今押すべき一つと、現在の状態と、読み物の区別が弱く、動くゲームの教材より開発用の操作盤に見える。
   - どう直すか: 現在の課題の主操作を一つだけ強調し、モード選択はまとまったナビゲーションへ、停止状態は盤面に、計測は補助領域へ移す。

## 実在作品との比較（2行）

比較対象は『スイカゲーム』。同じ物の合体と成長を見せる点で、次の一手・接触・成長の結果が盤面の出来事としてつながる表現に比べ、この画面は解釈を説明文と数値に預けすぎている。
不足は、合体した瞬間の主従が明快な動きと、現在の危険を言葉を読まずに把握できる情報配置。ルールが複雑な分だけ、その場で分かる視覚的な因果をさらに強める必要がある。

## AIが作った画面・動きに見えるか

見える。制作手段の断定ではなく、画面から受ける印象。強くそう感じた順に5つ。

1. どこが: 結果の数値・説明文・内訳が繰り返し増える。なぜ: 分からなさを動きの修正で解く前に、文章を追加して解決しようとした跡に見える。
2. どこが: 多数のボタン、チェック、計測折り畳みが一つの説明欄へ積まれる。なぜ: 必要な機能を順に足したままで、プレイヤーの一回の視線と操作に編集されていない印象がある。
3. どこが: 成長の予告に対し、実際は大きく内側へ収まり、長い留保説明が付く。なぜ: 予告を判断の道具に仕上げるより、例外説明で成立させた感じが残る。
4. どこが: スマホでは盤面の警告や方角注記まで縮小される。なぜ: レイアウトは狭幅に対応していても、読む対象・押す対象の優先順位を実機目線で詰めた気配が薄い。
5. どこが: 円・破線・淡い輪の効果と、緑灰色の矩形UIが全場面で似た強さを保つ。なぜ: 成功・危険・待機の感情の違いが弱く、汎用部品を組み合わせたプロトタイプに見える。

音: 未確認。音ありの切替状態のみ確認し、音色・音量・タイミングは評価していない。
