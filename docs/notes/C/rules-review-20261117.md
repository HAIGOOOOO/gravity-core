# 連投と敗因の審査

初見役は通常幅で盤面を操作し、390幅は静止画で確認。品質役は通常幅と390×844で盤面・補助ボタンを実操作。各10件、各★5。どちらも、演出より結果の確定が早いこと、注記の優先順位と固定のボタンが実操作と合わないことを機械的に見える点として挙げた。実機タッチと実聴は未確認。

| 指摘 | 対応 |
|---|---|
| ★ 致命的な射出に緑の連鎖予告が出る | 予測の終点を熱による終了として返す。盤面で「この射出で熱100・終了」を表示し、その照準の軌道と冷却の予告を止める |
| ★ 3投目を外周で止め、即時判定と着地後が混ざる | 連投の3投目は射出の熱を表示し、0.65秒だけ通常通り進めてから止める。熱99の左は射出直後の結果と明示 |
| ★ 帯が出た理由を履歴から読めない | 盤面の射出点に1・2・3の印、履歴に各方角、射出で加熱する側の補助ボタンに色を付ける |
| ★ 最初に投げられる範囲と補助ボタンが合わない | 外周全体を案内し、補助は直近の方角とその反対側へ更新する |
| ★ やり直すと前回の結果と見返しが消える | 3投目を同じ盤面へ戻し、比較に前回と今回の射出熱を並べる。両方を3投目直前から1/4速で再生 |
| ★ 熱26では方向選びの差が小さく、熱99では投げる前に危険帯が出ない | 結果から「熱99で試す」へ移動できる。致命予告を選択中に表示し、加熱する方角を外周の帯で示す |
| ★ スマホで見返しが再試行と熱内訳より先に出る | 連投と敗因は内訳と再試行を盤面直下へ。見返しをそのあとに置く |

親が右・右のあと通常幅と390pxで比較。同じ26.0から右は射出28.0、左は26.0。停止時16.9と14.9で、その間は両方−11.1。再試行後の低速で0.65秒を最後まで再生。390幅で再試行の下端579.4px、見返しの上端602.2px（スクロール132pxの時点）。熱99の右は射出で100.0・終了、左は自然冷却後98.9・その一投の直後は続行。結果を表示中は次の天体を隠す。

比較先の予兆は『ファイナルファンタジーXIV』の[「ギミックの訓練」](https://jp.finalfantasyxiv.com/lodestone/topics/detail/323be12f6a94adb359375e016130e9e1a200e753)、円周の射出点と圏外を追う例は[『スイカゲーム ぷらねっと』](https://www.nintendo.com/jp/topics/article/3b8d62d2-041a-416f-a214-bdd3dd94b2a4)。残るのは、熱99の左で続行したあとの着地と、限界外の代表天体から熱へ視線をつなぐ動き。
