# 連鎖5の描画と、連鎖1〜5の音

演出の比較画面は本物の合体イベントから盤面を作る。そのイベントの段1で、選んだ段5の表示用の値も上書きしていた。比較用の段をイベントにはっきり指定し、計測には演出器が持った層構成の最大を出した。単発は22、連鎖5と超新星は44層構成（その瞬間に使う層は経過時刻と同時発生数で変わる）。

## 描画

爆発ごとの大きさ、時間、色、向きは、描画する層で同じ。1回の計算結果を渡し、表示の始まる前・終わった後は各層の処理を省く。

アプリ内ブラウザー1280×720、音なし、前回と並べた状態。修正した比較ページで毎秒10回・合計30回の連鎖5を同じタブで交互に測った。描画JSの95%点は前2.20、1.80ms、後1.90、1.80ms。最大は前10.10、2.40ms、後2.20、2.40ms。表示間隔の95%点は前34.8・34.7ms、後34.6・34.4ms。1回ずつの先行計測では前後2.00→2.80msと逆にも振れた。速度が上がったとは断定しない。ページ全体の表示間隔16.7ms基準は未達。

旧側の乱数パネルを外し、連鎖5の0.033、0.100、0.267、0.533秒を同じ大きさで切り出すと4枚の画像が前後で一致した。単一環境・一場面の確認。[連鎖5の画面](juice-chain5-20261117.png)・[30回の計測画面](juice-44layers-bench-20261117.png)。

## 効果音

元の旋律の式は合体の階級が1上がると全音下がり、連鎖が1進むと全音上がる。両方が進むと連鎖の上がりが相殺される。3案は階級と独立した旋律、最初の天体の階級にそろえて同じ連鎖内で音を上げる、和音の重なりだけで段を伝える。短い連鎖で始まりの音が分かり、天体の大きさの音を保てる独立した旋律を選んだ。

余韻の片側を、段1〜5で1,046・1,174・1,318・1,567・1,759Hzと上げる。階級で変わる胴、衝撃の低音、合体のノイズは既存の音型。2段以降は旋律の1オクターブ下も重ねる。増やすのは音程差で、構成は6〜9層・全体上限12音。画面から1〜5段をWAVに保存でき、階級も段に合わせて0〜4へ上げて鳴らしている。

アプリ内ブラウザーのオフライン描画、音量100。連鎖1〜5のピーク0.413・割れ0、超新星0.484・割れ0。混在30回/秒を2秒流した時のピーク0.506、割れ0、12音、発音器の再利用358、入力成分の拒否0、終了後0音。音量0はピーク0。音の強さの聞き分け、実聴と機器経由の映像同期は未確認。[計測結果と保存リンクの画面](juice-chain-audio-20261117.png)。
