# 題目11　盤面全体へ届く点の衝撃波

方針11・2周目。突き返し18を受け、一つの演出を本体へ接続した。11/20の中断時点で途中保存。動く見本は [合体の衝撃](https://haigooooo.github.io/gravity-core/team-c/dev/impact.html)。

- [合体1回の本体動画](2026-11-20_merge.webm)。
- [実計算5連鎖の本体動画](2026-11-20_chain.webm)。
- [超新星の本体動画](2026-11-20_nova.webm)。

各5秒・無音。開発用サーバーで本体のstartAppへ固定配置と録画を取り付け、同じ更新・描画・演出を通した。ゲーム本体のファイルは変更していない。固定配置は `src/dev/impact-fixtures.ts`、再実行は `node src/dev/impact-runtime-probe.mjs 5188`、`/?seed=13&impact=merge`（chain・novaも可）。録画ボタンを押すと開始する。

停止・スローは本体のEffectsLayerに接続漏れがあったため再接続。以前の時間制御を使い、同時の弱い合体が強い事件を消さないようにした。合体は点の波と飛散を端まで広げ、段5と超新星で大きさ・波の数・余韻・揺れを増した。動きを減らす設定では静止した点の明るさで示す。盤面の天体は現行の描画を使用し、Dの点の共通部品は未統合。

画面で合体1回、実計算の5連鎖（tick 1→2→3→195→255、10,190点）、超新星（45,000点）を確認。型検査・本体・公開用ビルド・範囲検査が通過し、通常768試験中767通過、既知のoverlimit 1件。追加した本体の入口の試験1件も通過。録画は合体197描画/5秒だった。実機60fpsの確認、変更後の390・768・1440幅の検証、録画の全コマの確認、最終の公開版照合と見た目の合否は中断時点で未完。

## 前回の3案（版10、突き返し18）

[前回の見本](https://haigooooo.github.io/gravity-core/team-c/dev/dots-motion.html)。手元では開発サーバーの `/dev/dots-motion.html`。「合体1回」「5連鎖」「超新星」のどれかを押すと再生。同じ配置・得点・核熱・時刻で比べる。広い画面は横並び、スマホとタブレットはA〜Cを切り替えて見る。

- [A 流入](2026-11-17_motion_a.jpg) — 射出した天体から合体先に、点が一筋で流れ込む。
- [B 反転](2026-11-17_motion_b.jpg) — 合体点を横切る帯が、点の明るさを順に切り替える。
- [C 引力](2026-11-17_motion_c.jpg) — 合体の近くの格子が合体点へ寄り、もとの位置へ戻る。

超新星は各案とも中心から外へ点の波が広がる。Aは太い帯、Bは細い縁、Cは明滅に格子の移動が加わる。この3案は小さく控えめだったため、突き返し18になった。

## 手本と照合した点

- NothingのGlyph Matrixと同じく、間隔が一定の丸い点で形を作る。ここでは天体の輪郭の点が格子から離れて滑らかに動く。[Nothing Phone (3)](https://np.nothing.tech/products/phone-3)
- Halftone Vortexと同じく、中心へ向かう点の動きで方向を示す。合体に向かう流れは短い一筋に絞った。[Halftone Vortex](https://pro.reactbits.dev/docs/components/halftone-vortex)
- flipdotsと同じく、反転した点と背景の明度差で帯を見せる。画面では点の直径と段階的な明るさも使う。[flipdots](https://flipdots.cargo.site/text)

## ブラウザーで確認した点

- 390×844で3案を同じ合体時刻0.96秒に切り替え。3秒の5連鎖で23,820点、核熱22を確認した。
- [768×1024](2026-11-17_motion_768.jpg) では1面を表示。超新星で動きを減らす設定と一時停止を切り替え、再生位置をEndキーで3秒へ送ると核熱46になった。
- [1440×900](2026-11-17_motion_compare.jpg) では377pxの盤面が3面並ぶ。390・768・1440幅で横スクロールなし。アプリ内Chromiumで確認した。実機での計測は次の段階。

合体前の0.16秒に天体が接近する。「動きを減らす」と接近の移動も止まる。背景の格子は共通のパスを使い、事件で変わる点だけ描き直した。3案を並べ各3秒を60コマ/秒でサンプリングした時、1コマに組み立てる円の最大数は合体9,513→2,489、5連鎖9,513→3,993、超新星14,409→6,359。円を描く指示の数で、実機の表示間隔は未計測。
