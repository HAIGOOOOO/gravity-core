# 題目11　点の動きの3案

[動く見本](https://haigooooo.github.io/gravity-core/team-c/dev/dots-motion.html)。手元では開発サーバーの `/dev/dots-motion.html`。「合体1回」「5連鎖」「超新星」のどれかを押すと再生。同じ配置・得点・核熱・時刻で比べる。広い画面は横並び、スマホとタブレットはA〜Cを切り替えて見る。再生位置を動かしたり、「動きを減らす」で比較したりできる。

- [A 流入](2026-11-17_motion_a.jpg) — 射出した天体から合体先に、点が一筋で流れ込む。
- [B 反転](2026-11-17_motion_b.jpg) — 合体点を横切る帯が、点の明るさを順に切り替える。
- [C 引力](2026-11-17_motion_c.jpg) — 合体の近くの格子が合体点へ寄り、もとの位置へ戻る。

超新星は各案とも中心から外へ点の波が広がる。Aは太い帯、Bは細い縁、Cは明滅に格子の移動が加わる。ゲームに入れる案は持ち主が選ぶ。

## 手本と照合した点

- NothingのGlyph Matrixと同じく、間隔が一定の丸い点で形を作る。ここでは天体の輪郭の点が格子から離れて滑らかに動く。[Nothing Phone (3)](https://np.nothing.tech/products/phone-3)
- Halftone Vortexと同じく、中心へ向かう点の動きで方向を示す。合体に向かう流れは短い一筋に絞った。[Halftone Vortex](https://pro.reactbits.dev/docs/components/halftone-vortex)
- flipdotsと同じく、反転した点と背景の明度差で帯を見せる。画面では点の直径と段階的な明るさも使う。[flipdots](https://flipdots.cargo.site/text)

## ブラウザーで確認した点

- 390×844で3案を同じ合体時刻0.96秒に切り替え。3秒の5連鎖で23,820点、核熱22を確認した。
- [768×1024](2026-11-17_motion_768.jpg) では1面を表示。超新星で動きを減らす設定と一時停止を切り替え、再生位置をEndキーで3秒へ送ると核熱46になった。
- [1440×900](2026-11-17_motion_compare.jpg) では377pxの盤面が3面並ぶ。390・768・1440幅で横スクロールなし。アプリ内Chromiumで確認した。実機での計測は次の段階。
