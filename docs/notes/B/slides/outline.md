## 進め方

- 8枚。企画30秒 → 分担と日程30秒 → A・B・C・D各30秒 → デモ60秒 → 今後30秒。計4分30秒、残り30秒を読み込みと交代の余裕にする。
- 下の「載せる事」だけを画面に載せる。出典・操作手順・確認待ちは発表者の手元用。
- 原稿は各30秒以内を目安にした下書き。人が声に出して測った時間ではない。本人欄を埋めてから全員で5分以内に収める。
- Cの `slides/my_part.md` と合体・連鎖の動画を採用する。Dは指定の発表版の原稿と盤面3案を使い、採用済み案3の状態へ更新する。本人の判断・確認は、資料の説明から捏造しない。
- A〜Dの「本人欄」は、実際にした判断・確認を各本人が1文で入れる。AIによる実装・検査を、本人が行った経験として話さない。
