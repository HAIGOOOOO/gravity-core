# 担当Dの中間発表

## 題
点の格子の盤面

## スライドに載せる事
- 同じ6天体の盤面を3案で比較。
- Aは点の集積、Bは輪郭と芯、Cは合体の衝撃波を強調。
- 390×844と白黒表示で、小粒子と限界線の見え方を確認。

## 話す事
担当Dです。スマホの盤面を、同じ6つの天体を使って3案作りました。Aは点の密度、Bは輪郭と芯、Cは合体時の波を盤面の端まで見せます。試作にはAIを使い、私はスマホの大きさと白黒表示で、小さい天体や境界の見え方を確かめました。3案を見比べて一案を選び、本体へ反映する予定です。
