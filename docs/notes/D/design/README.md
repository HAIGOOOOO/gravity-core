# 点の格子の盤面案

3案とも 390 × 844 px。恒星と6天体、合体する2体の位置、得点、核熱量、次の3体を揃えた。残り時間と得点はレイアウトを比べるための表示例。

| 案 | PNG | 描き方 |
| --- | --- | --- |
| A 集積 | [盤面A](2026-11-19_board_a.png) | 64列。明るい点の面と片側の陰で、天体の重さを出す。 |
| B 輪郭 | [盤面B](2026-11-19_board_b.png) | 80列。太い外周と独立した芯で、大小の形を読みやすくする。 |
| C 点の衝撃波 | [盤面C](2026-11-19_board_c.png) | 80列。合体の接点から丸い点がはじけ、波が盤面の縁まで届く瞬間。 |

共通の盤面は `/dev/dots-board.html`。ボタンで切り替え、白黒表示で形を比較できる。

## 手本と見比べた結果

- [Nothing Phone (3) の写真](https://design-milk.com/the-nothing-phone-3s-glyph-matrix-turns-notifications-into-pixel-art/)と同じく、余白と丸い点の明暗で形を読む。盤面では白の記号の代わりに大きさ・色・点の並びで天体の段階を伝える。
- [Halftone Vortex](https://pro.reactbits.dev/docs/components/halftone-vortex)と同じく、点の列で力の向きが見える。盤面では渦を常時回さず、天体へ向かうずれを格子間隔の0.6倍以内に留め、合体のときだけ接点から外へ波を出す。
- [Flipdots](https://flipdots.cargo.site/text)の丸い点が点く・消える語彙を使う。盤面は二値だけでなく、固定の明るさの段と星の温度色を使う。

## 390 × 844 の見え方

- Tier 0 は盤面の左側。中心列の点は64列で7点、80列で7点。最小の直径に加え、B・Cは明るい十字を使い、白黒のC案でも他の天体と区別できることを画面で確認。第三者がTierの数字を当てる試験は未実施。
- 普段の画面でぼかし・グロー・グラデーション・カード・絵文字・四角いドット・紫は使わない。Cの波と飛ぶ点は事件の例外。限界リングは合体以外の天体を覆わないよう残した。
- Cは強い波で合体する2体の外周の一部が見えにくくなる。実装案を決める時は、波のピーク前後でも合体の相手が追えるかを確認する。
- 静止画は同じ配置・数値を揃えるためにCanvasで制作した。実装する案は持ち主が選ぶ。
