# 題目00・1周目（2026-10-20、制作途中）

## 作る前に決めた事
一文の意図: 合体の直前に内へ吸い、直後に外へ裂く逆転で、重力の塊が生まれたと伝える。
主色は橙（物質と得点の放出）、白は最短の白熱と読む数字、暗い面は圧縮と空洞。色をランダムに増やさず、seedは向きと破片の形へ使う。
書体は端末のsystem-uiの太い数字。最初の比較では書体の素材を増やさず、本文は普通の日本語。飾りの英字や気取った題は足さない。
制約: 全画面の白で覆わず、実際のPredictionと限界リングを演出より上へ戻す。同じ部品の個数を層に数えない。

## 見た実物と出典
以下の採用・不採用は制作者の判断。外部画像をゲームの素材に転載しない。すべて2026-10-20閲覧。

1. **Tetris Effect: ConnectedのZone画面**（Enhance、公式ページ。掲載日の表示は未確認）。[公式説明と画面](https://www.tetriseffect.game/connected/)。画面の周囲へ細かい光が広がっても、中央の落ちる場所は強い境界で独立している。静止画を実際に表示して見た。採るのは「遊ぶ場所の輪郭を最後に戻す」事。色数と発光の量をそのままコピーする事はしない。Zoneの時間停止は公式の説明を読んだが、この回では動画の時間を測っていない。
2. **Cassiopeia Aの光の反響**（NASA / ESA / CSA / STScI / Jencson / DePasquale、2025-01-14）。[公式資料](https://science.nasa.gov/asset/webb/cassiopeia-a-light-echoes-time-lapse/)。縮小された3時点の静止画と公式の説明を確認した。どこも同じ円で光るのではなく、塵の筋が違う位置へ現れる。採るのは、遅れて広がる角ばった薄膜と方向の偏り。科学的な時間尺度や疑似色は再現しない。縮小図のため細部の判断は限定的。
3. **Artemis I打上げの写真**（NASA / Joel Kowsky、撮影2022-11-16、記事2024-11-15）。[公式写真記事](https://www.nasa.gov/image-article/two-years-ago-artemis-i-liftoff/)。原寸リンクをブラウザーで表示して観察。細い白い芯、強く向きのある噴流、広がった低い橙の煙の3段に分かれる。採るのは、細い芯と広い噴出を一つの均等な粒群にしない事。ロケットそのものと写真素材は使わない。

別候補の[Balatro公式トレーラー](https://www.playbalatro.com/)も開いたが、映像の途中の画面取得が失敗した。サムネイルだけから採点の動きや秒数を判断せず、上の3件の代わりには数えない。

## 3案
- A 圧縮して割れる: 先に内へ流れる筋と暗い圧縮、次に外殻と鉱物片。連鎖では物質の大きな塊と外側の圧縮板を加える。
- B 一方向へ噴き出す: 核のまわりの接線を向きとして、両側の狭い噴流へ物質を集中させる。全方位の均等な粒群を避ける。
- C 遅れて余響が広がる: 噴出した物質を中心近くへ残し、遅い角のある反響膜が外へ広がる。爆発後の空間を長く見せる。

仮にAを選ぶ。外へ散る前に内へ吸う方向の逆転が、核へ積もるゲームの出来事へ結び付くため。Bは向きは明快だが、反対側の山へ何が起きたのかを誤読させる危険がある。Cは大きい余響に向くが、普通の合体には遅い。

## 現在の限界
dev/juice.htmlだけの方向見本。本番のEffectsLayerはまだ差し替えない。通常20種類・連鎖5と超新星は最大24種類の描画部品を実装したが、40層以上という基準は未達。時間停止・スロー・連鎖が続く時の遷移も未実装。この1周目を完了・提出とは扱わない。原画の形、時刻ごとの見え方、測定を先に残し、次に層の意味を増やしてから動画で再審査する。
