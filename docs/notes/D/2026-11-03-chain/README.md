# 実計算の連続合体・1周目の補助資料

実際の計算による合体tickは1/2/3/195/307、連鎖1〜5、得点合計10,190。
連鎖数と得点の上書きは行わず、イベントの消費・誕生IDもテストでつながる事を確認した。

real-chain.webm はこの環境で記録した無音動画。recording-frames.png はその再生中に同じCanvasから保存したコマ抜粋、recording-timing.json はその実測。画面共有・カメラ・マイクは使っていない。

**通常速度の動画審査の証拠ではない。** 86.563秒で94描画、平均1.086描画/秒、描画間隔95%1020.8ms。低い描画回数の原因は未確定。このファイルを60fpsや「気持ちいい」「派手さ9/10」の合格根拠に使わない。

**記録後に終了条件を変更した。** この映像は5段目から演出時刻1.6秒で終了した版で、JSONのpeakAndTailCaptured=trueもその旧条件。全余韻が記録されたという意味ではない。現在の実装は、残っている演出が寿命を迎えるまで待つ。120秒の上限に当たった時は未完と表示する。新条件の録画は未保存。

recording-page.jpg は録画中の画面。全ページを指定して撮ったが、ブラウザーの出力範囲に録画欄は入っていない。画面に見えない部分の根拠にはしない。

通常のブラウザーでの確認先は /dev/chain.html。push後は既存のCIが専用ページを自動撮影する。/dev/juice.htmlの1〜5ボタンは従来どおり指定値の形の比較で、実際の連続合体とは区別する。

chain-page.jpg は専用ページの実計算5連鎖・10,190点とイベントログ。responsive.json は640×360 / 900×600 / 1280×720の表示枠での寸法のスナップショットで、盤面と演出の矩形は一致、横方向のはみ出しは無し。360×640でも同じ一致を画面から確認したが、そのJSONは未保存。実機の検証ではない。

## 自動撮影（0c9701d）

[previewの成功記録](https://github.com/HAIGOOOOO/gravity-core/actions/runs/41596343003)。ci-chain.webm と ci-chain.png は、[公開動画](https://haigooooo.github.io/gravity-core/team-d/videos/chain.webm)と最終画像を取得したコピー。取得後のブランチ更新で公開URLの中身は変わる。

元動画は960×720、25fps符号化、6.88秒。最終画像は実計算tick519、5連鎖、10,190点。符号化fpsはゲーム本体の描画fpsの計測ではない。

ci-sequence.jpg は同梱ffmpegによって8fpsへ再標本化した動画の盤面部分を時系列に並べたもの。ラベルは出力コマ番号/8による目安で、厳密な入力動画PTSではない。末尾の重複コマもある。初期の再生と「最初から再生」ボタンの押し直しが含まれるため、同じ三段目が2回現れる。ここから連続視聴の気持ちよさや匿名の1〜5判別を合格にしていない。
