# 実計算の連続合体・1周目の補助資料

実際の計算による合体tickは1/2/3/195/307、連鎖1〜5、得点合計10,190。
連鎖数と得点の上書きは行わず、イベントの消費・誕生IDもテストでつながる事を確認した。

real-chain.webm はこの環境で記録した無音動画。recording-frames.png はその再生中に同じCanvasから保存したコマ抜粋、recording-timing.json はその実測。画面共有・カメラ・マイクは使っていない。

**通常速度の動画審査の証拠ではない。** 86.563秒で94描画、平均1.086描画/秒、描画間隔95%1020.8ms。低い描画回数の原因は未確定。このファイルを60fpsや「気持ちいい」「派手さ9/10」の合格根拠に使わない。

**記録後に終了条件を変更した。** この映像は5段目から演出時刻1.6秒で終了した版で、JSONのpeakAndTailCaptured=trueもその旧条件。全余韻が記録されたという意味ではない。現在の実装は、残っている演出が寿命を迎えるまで待つ。120秒の上限に当たった時は未完と表示する。新条件の録画は未保存。

recording-page.jpg は録画中の画面。全ページを指定して撮ったが、ブラウザーの出力範囲に録画欄は入っていない。画面に見えない部分の根拠にはしない。

通常のブラウザーでの確認先は /dev/chain.html。push後は既存のCIが専用ページを自動撮影する。/dev/juice.htmlの1〜5ボタンは従来どおり指定値の形の比較で、実際の連続合体とは区別する。
