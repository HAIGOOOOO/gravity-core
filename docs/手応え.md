# 手応えの設計図（全員が使う。書き換えるのはリーダーだけ）

2026-10-16 版。持ち主が ChatGPT に調べさせた 2 本の資料（`docs/research/`）と、リーダーの 19 案をまとめ直した物です。担当 C と D の手順書は、ここを土台にしています。

数字はすべて**最初に試す値**です。触って詰めます。時間は 1 コマ = 16.7ms（60 コマ毎秒）。

## 1. いちばん大事な考え方

1. **強さは「量」ではなく「使える道具」で分ける。** 通常の合体を 100、超新星を 150 にするのではなく、小さい出来事は「形」だけ、中くらいで「局所の光と小さな寄り」、大きいと「カメラと時間と背景」、最大の出来事だけが「画面全体」を使える。こうしないと、強い演出を足すたびに「強い」の基準が消える。
2. **何も起こさない瞬間も設計する。** 大きい合体の直後や連鎖の終わりに、新しい飾りを一瞬出さない「間」を置くと、直前の出来事が立つ。
3. **ゲームの判定は、演出を待たない。** 合体・衝突・連鎖の判定はすぐ終わる。演出だけが少し遅れて順番に出る。演出のために、同じ天体が触れているのに合体しない、を作らない。
4. **手応えはルールを説明する。** 「合体した」「まだ連鎖できる」「どこが危ない」「大きい出来事だった」が、数字より先に体で分かること。
5. **全部の反応が重力を語る。** 粒は重力で曲がる、核の光は山の重さを感じる、空間がゆがむ。これがほかの落ち物パズルと違う所。

## 2. 4 つの階級と、使える道具

| 階級 | 例 | 使える道具 | 使えない道具 |
|---|---|---|---|
| **小** | 着地、Tier 0〜2 の合体、こすれ | 天体の形（潰れ・弾み・揺れ）、近くだけの小さな光と粒 | 画面の揺れ、ズーム、時間、背景 |
| **中** | Tier 3〜5 の合体、2〜3 連鎖 | 小の全部＋局所の光、ごく小さい寄り（0.4〜1.3%）、短いヒットストップ | 画面全体の光、大きい揺れ、スロー |
| **大** | Tier 6〜7 の合体、4 連鎖以上、限界を越えた瞬間 | 中の全部＋向きのある画面の揺れ、寄り（〜2.2%）、ヒットストップ、背景を少し暗くする、白い 1 コマ（その場所だけ） | 画面全体の白、長いスロー |
| **最大** | Tier 8 の誕生、超新星、負けた瞬間 | 全部（画面全体、スロー、大きい変形） | — |

- **予算**: 同じ瞬間に使えるのは、最大 1 件・大 2 件まで。小はいくつでも。あふれた物は捨てずに「1 つ下の階級の道具」で出す（画面全体の白 → その場所の白い縁、など）。
- **道具ごとの間隔**: 画面の揺れ・寄り 0.12〜0.18 秒、背景の暗転 0.18〜0.25 秒、画面全体の白 0.33 秒以上（1 秒に 3 回を超えて光らせない。光に敏感な人のため）。
- **最後に必ず上限をかける**: いくつ重なっても、傾き ±0.6°、寄り ±3%、中心のずれ 盤面の半径の 2% まで（超新星だけ別枠）。

## 3. 時間

- **ヒットストップ**（`EffectsLayer.timeScale()` で頼む。上限は `src/shared/time.ts`）:

  | 合体 | 止める長さ |
  |---|---|
  | Tier 0〜2 | 0（止めない） |
  | Tier 3〜5 | 17〜33ms（1〜2 コマ） |
  | Tier 6〜7 | 33〜50ms |
  | Tier 8 の誕生 | 50〜67ms |
  | 超新星 | 専用の流れ（スロー → 止め → 戻り） |

  同時に起きても、長さを足し算しない（長い方だけ）。
- **止まっている間も、末端は動く**: 天体と山は止める。火花・光・カメラの戻りは動かす（`update(dt)` の dt は実際の時間）。「ゲームが固まった」ではなく「衝撃で時間が止まった」に見せる。
- **入りは速く、戻りは遅く**: スローに入るのは 30〜60ms、戻るのは 120〜220ms。
- **連鎖の時間**: 2.5 秒の連鎖の期限は、ゲームの時間（tick）で数えている。スローの間は期限も遅く進むので、不公平にはならない。
- **同時に起きた合体は、見せ方だけ階段にする**: 判定は同時のまま、光と得点だけを 25〜75ms ずつずらして出す（全体で 0.3 秒以内）。4 個目からは間隔を詰める。
- **間**: 3 連鎖以上の終わりに 70〜130ms、大きい合体の直後に 100〜160ms、新しい飾りを出さない（天体の動き・危険の表示・操作の反応は止めない）。
- **超新星の後の余韻だけ早送り**: 残った光や粒だけ、1.5〜2 倍の速さで消して、遊びに戻す。

## 4. 担当の割り振り

番号は資料の番号（D = Deep Research の報告、G = もう 1 本の 60 案）。

### 担当 C（動きと手応え）
- 階級と予算と上限の仕組み（2 章）。演出は全部これを通す。**最初に作る。**
- 合体: 吸い付き → 白い 1 コマ（大以上） → **新しい天体の誕生**（暗い輪郭を 40ms 先に出し、模様と色が 80〜140ms で広がる。大きさは 0.82 → 1.07〜1.12 → 1.0 を 160〜220ms、大きい天体ほど行き過ぎを小さく）→ 中の模様だけ遅れて揺れる → 消えた 2 つの輪郭が 80〜180ms 残る（D: V-07、G: 9・11・29・40）
- 大きい天体ほど、揺れがゆっくり（小 8〜12Hz、大 2.5〜5Hz。振幅は大きいほど小さく）（D: V-08・V-11）
- 押し合う所だけ 2〜5% へこむ、接する所に薄い影（D: V-09・V-14、G: 28）
- 同時の合体の階段、間、連鎖の段の格上げ（3・5・8 連鎖で、道具を足すのではなく置き換える）、連鎖が終わった時の小さな印（D: T-01・T-02・T-08、G: 13・16・17・18・21）
- **連鎖の期限の輪**: 生まれた天体のまわりに 2.5 秒で減っていく細い輪。最後の 0.4〜0.5 秒で変化（D: I-04、G: 12）。**2 本の資料がそろって 1〜3 位に挙げた物。**
- 合体の光が周りの天体の縁を順に明るくする波（D: V-16、G: 33）
- **粒の文法**: 核へ向かう出来事は放射状、曲げ投げや回転は接線方向、粒は核へ曲がって落ちる（本物の重力の 0.1〜0.35 倍）（D: G-12、G: 39）
- 曲げ投げだけ残像 3〜5 枚、速さで長さが変わる尾、核に一番近づいた瞬間の光の刃（D: V-12・V-13・G-05、G: 31）
- 投げた場所に小さな跡、山が落ち着いたら飾りも静まる（G: 4・8）
- 危ない時: 越えそうな天体の外向きの速さ（D: I-05）、立て直した時の冷える変化（G: 45・58）
- 超新星の後: 空洞の跡、破片が一時的に環になる、余韻の早送り（D: G-10、G: 23・57）
- 重力の操作: 等ポテンシャル線（重力をゆるめると間隔が広がる）、戻した瞬間に力の線が核へ巻き戻る（D: G-02、G: 46・49）（芯が決まってから）
- 重さが落ちたら自動で飾りを減らす。削る順は、背景の飾り → 光と残像 → 変形。**天体の形・合体の見分け・危険の表示・照準は絶対に削らない**（D: I-08）
- 動きを減らす設定を 0〜1 の「動きの量」にして、全部の動きをそこから決める。0 でも、合体や危険は光や線で伝わる（D: S-01）

### 担当 D（形と色）
- **9 段階を、大きさ以外の形でも見分ける**（縁の太さ、模様の数、外の小さな飾り。3 段階ごとにはっきり、隣どうしは縁の太さ 10〜15% 差。白黒でも分かる）（D: I-01、G: 42）
- **限界リングの手前の予兆帯と、危ない方角の表示**: リングの内側に薄い帯、山が近い方角だけリングを少し太く。赤は「越えた」にとっておく（D: I-02・I-03、G: 41）。**2 本の資料がそろって上位に挙げた物。**
- **予測の道すじを点の列に**: 等しい時間おきの点で、核に近づくほど間隔が開く（重力で速くなるのが見える）。着く場所に薄い印。不確かなら破線（G: 1・2）
- 引く強さの目盛り（G: 3）
- 核: 光の輪（コロナ）が、山の重い側へ少し厚くなる。大きい合体で光の輪だけ反対へ 1〜3px ゆれる。**核の位置そのものは絶対に動かさない**（D: G-07・G-08、G: 51）

- 背景: 星空・中景・盤面を別の速さで動かす薄い奥行き、大きい天体の近くで星が 1〜5px ずれる重力レンズ（D: V-04・G-01、G: 47）
- 核に近い天体がわずかに核の方へ伸びる潮汐（1〜2%）（D: G-03）
- 模様だけ本体より 30〜60ms 遅れて回る（D: V-10、G: 30）

## 5. やりすぎの失敗（全員が守る）

| 失敗 | 対策 |
|---|---|
| 全部の合体が派手 | 階級で道具を分ける |
| ヒットストップが重なる | 足し算しない。長い方だけ |
| 画面全体のズームが多い | 照準中は止め、背景の動きに置き換える |
| 強い光が続く | 天体の輪郭はいつも一番上に描く |
| 粒が残り続ける | 使い回す箱と上限 |
| 危険の表示が激しすぎる | 危険の場所と程度は、止まった形でも伝える |
| いつも背景が動いている | ふだんはゆっくり。静かだから大きい出来事が立つ |
| 色だけで大事さを表す | 形・模様・位置・時間も使う |
| 成功の演出が危険を隠す | 危険の表示は成功の演出より上 |
