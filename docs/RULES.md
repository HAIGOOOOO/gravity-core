## 変えた理由

軌道型を実際に遊んだら、「軌道に乗せる」「動いている天体に当てる」「速すぎると合体しない」の全部が難しく、初めての人が合体までたどり着けなかった。題材（中央の核、合体、核熱量）は残し、天体が**回り続ける**のではなく**積もる**形にした。

## ルール

1. 盤面の中央に核がある。その外側に限界リング（半径 320）と射出リング（半径 425）がある。
2. 盤面を押すと、押した方角の射出リング上に次の天体が出る。離すと核へ向かって落ちる。射出の値は、受け付ける時に丸める（角度は 2π/2^32 の格子、速度は整数の px/秒。`quantizeLaunch`）。入力ログと共有の文字列には丸めた値が残る。速さの範囲の判定は丸めた後の値で行い、許し幅は 1（丸めで最大 0.71 ずれるため）。
3. 天体は核や他の天体に当たって止まり、核のまわりに積もる。重力は中心向きで、強さは一定。盤面全体は毎秒18度（仮、検証中）、時計回りに流れる。射出中も山も位置と速度の向きに同じ回転を加え、回転だけでは天体同士の距離や速度の大きさを変えない。2026-10-22追加、戦法比較で検証中。
   合体で大きくなる天体の位置補正が接している山へ伝わった時、既に着地した天体の外向き速度を増やさない。接線方向へ転がる動きと、射出中の天体の衝突は残す。密度が高く、実際に限界外へ積もった山は従来どおり熱を上げる。2026-10-21追加。
4. **同じ Tier の天体が触れると、必ず合体する**（速さの条件はない）。1 つ上の Tier が 1 体生まれ、得点が入る。生まれた天体は 0.12 秒かけて本来の大きさになり、周りを押しのける。**合体すると核熱量が下がる。** 連鎖1/2/3/4/5以上で2/5/8/11/14（0未満にはならない）。2026-10-21追加。
5. Tier 8 どうしが触れると、両方が消える（超新星）。45,000 点を基礎点として連鎖倍率が掛かり、核熱量は最大40下がる。通常合体の冷却は重ねない。
6. 積もった天体の外側の端が限界リングを越えている間、核熱量が毎秒 22 上がる。越えた天体がなければ毎秒 14 下がる。撃ってから・生まれてから 1.2 秒以内の天体は数えない。
7. 核熱量が 100 でゲームオーバー。
8. 得点 = その Tier の基礎点 × 連鎖の倍率。**連鎖**は、合体で生まれた天体が 2.5 秒以内にまた合体すると 1 つ増える（画面には出さないが、期限の後 0.085 秒までは間に合ったと数える）。倍率は 1.0、1.5、2.0、2.5、3.0（最大）。
   合体・超新星は`chainStage`（1〜5）と`stageAdvanced`（新しい段へ進んだか）を出す。6連鎖以上は5段目のまま、得点倍率も冷却も上限を維持する。画面と音は1段目から全部を盛らず、この段を使って要素を一つずつ増やす。段の名前と文字の本番表示はD担当。
9. 次に撃つ天体は 3 個先まで見える。**固定組20個を混ぜた袋**から順に出し、空になってから補充する。到達した最高Tierが0〜1ならTier0/1を14/6個、2なら0/1/2を9/7/4個、3なら0/1/2/3を7/6/4/3個、4以上なら0/1/2/3/4を6/5/4/3/2個。到達Tierが変わっても残りの袋は捨てず、次の補充から反映する。最初の2投はTier0で固定し、その後から袋を使う。2026-10-21追加。
10. 開始時は、核の真上に Tier 0 が 1 個置いてある。真上を押して離すだけで最初の合体が起きる。
11. **射出後の一手「崩壊」**: 最高Tier3で解放し、合体で連鎖数ぶんたまる12点のゲージをすべて使う。成功した射出から1.2秒未満、一投につき一度。1.2秒ちょうどは使えず、拒否された射出では窓を延長しない。崩壊は1.2秒続き、核への重力が1.8倍、同Tier同士を隙間160以内で引き寄せ、通常の熱変化に毎秒−30を加える。熱0で止まる。限界外なら通常の+22と合わせ毎秒−8、限界内なら−14と合わせ毎秒−44。別の崩壊が続いている間は再使用できない。**本人の2026-10-22の選択により、操作ボタンはデモだけ。本体のボタンは未接続。**

## 操作

- **押して離す**: 核へまっすぐ落とす（速さ 260）。
- **押したまま引いて離す**: 引いた向きへ投げる。引いた距離 24〜150px が速さ 200〜620 になる。外向きの成分は取り除かれる（輪に沿う向きまで）。天体は重力で曲がって落ちる。
- この変換は `src/shared/launch.ts` の `aimVelocity` にある。自分で計算し直さない。
- 押している間、**最初に何かへ触れるまでの道すじ**を出す（`Prediction`）。当たる相手が同じ Tier なら `willMerge` が true になる。他の天体の相対配置は固定した目安だが、全体の回転は各時刻に含める。
- 同Tierへの合体が見込める時は、最大まで成長した天体と接触の押しのけを解いた`mergePreview`も出す。破線は成長後の目安、赤は限界を越える可能性。時間経過・連鎖・限界の猶予は含まず、未来の配置や敗北を保証しない。超新星や当たり先が不確かな時は出さない。
- 撃った後、次に撃てるまで 0.5 秒。待っている間も照準はできる。

## 出来事（`GameEvent`）

| kind | いつ | 主な中身 |
|---|---|---|
| `launch` | 撃った | 場所、Tier |
| `land` | 撃った天体が初めて何かに触れた | 場所、Tier、`impactSpeed`（ぶつかった速さ） |
| `merge` | 合体した | 場所、元の Tier、生まれた Tier、`scoreDelta`、`chain`、`heatDelta`（実際に冷えた量、0以下） |
| `supernova` | Tier 8 どうしが消えた | 場所、`scoreDelta`、`heatDelta`（実際に冷えた量、最大−40）、`chain` |
| `overLimitStart` | 山が限界リングを越えた | なし |
| `overLimitEnd` | 越えた天体がなくなった | なし |
| `collapse` | 射出後の崩壊を受け付けた | 核の場所。冷却量は続くtickの状態へ反映 |
| `gameOver` | 核熱量が 100 になった | なし |

盤面の状態（`GameSnapshot`）には、盤面全体の `overLimit` と、天体ごとの `overLimit` がある。どの天体が熱量を上げているかを見せるのに使う。

`intervention`は解放・ゲージ・使える残り時間・使用済み・継続時間を渡す。`coolingThisTick`は直前のtickで崩壊が実際に冷やした量（自然変化との差分）。熱0未満の架空の冷却を含めない。

## 保存と再生（2026-10-22）

REPLAY_FORMATは8、共有ルールは7、共有文字列の形式は3、途中盤面の形式は4。受理した崩壊は直前の`LaunchInput.collapseTick`に記録し、次の射出と同tickなら崩壊を先に再生する。窓外・次の射出後・終了tick後の記録は拒否する。共有の形式3は、崩壊がある場合だけ入力の後に件数・射出の添字・射出からのtick差を追加する。再生シーク・共有検証も同じ入力順を使う。重力の試作専用入力と通常の崩壊を混同しない。
