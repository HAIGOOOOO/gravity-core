# RULES — いまのルール（2026-10-08 に変更）

**このファイルが、ルールと操作についての正です。** `SPEC.md` は「軌道に乗せる」型だった頃の企画書で、ルール・物理・操作の章（2〜5 章、7 章、3.8 の予測など）は古くなりました。`SPEC.md` で今も使うのは、色と文字（6.1）、画面の配置（6.2〜6.4）、重ねて出す画面（6.6）、ランキングページ（6.7）、読みやすさの配慮（6.9）、音の作り方（8.4）、保存（10 章）です。食い違ったら、このファイルと `src/contracts/`、`src/game/constants.ts` が勝ちます。

## 変えた理由

軌道型を実際に遊んだら、「軌道に乗せる」「動いている天体に当てる」「速すぎると合体しない」の全部が難しく、初めての人が合体までたどり着けなかった。題材（中央の核、合体、核熱量）は残し、天体が**回り続ける**のではなく**積もる**形にした。

## ルール

1. 盤面の中央に核がある。その外側に限界リング（半径 320）と射出リング（半径 425）がある。
2. 盤面を押すと、押した方角の射出リング上に次の天体が出る。離すと核へ向かって落ちる。
3. 天体は核や他の天体に当たって止まり、核のまわりに積もる。重力は中心向きで、強さは一定。
4. **同じ Tier の天体が触れると、必ず合体する**（速さの条件はない）。1 つ上の Tier が 1 体生まれ、得点が入る。生まれた天体は 0.12 秒かけて本来の大きさになり、周りを押しのける。
5. Tier 8 どうしが触れると、両方が消える（超新星）。45,000 点、核熱量 −40。
6. 積もった天体の外側の端が限界リングを越えている間、核熱量が毎秒 22 上がる。越えた天体がなければ毎秒 14 下がる。撃ってから・生まれてから 1.2 秒以内の天体は数えない。
7. 核熱量が 100 でゲームオーバー。
8. 得点 = その Tier の基礎点 × 連鎖の倍率。**連鎖**は、合体で生まれた天体が 2.5 秒以内にまた合体すると 1 つ増える。倍率は 1.0、1.5、2.0、2.5、3.0（最大）。
9. 次に撃つ天体は 3 個先まで見える。出るのは Tier 0〜4 だけで、到達した最高 Tier に応じて範囲が広がる（`QUEUE_TABLE`）。
10. 開始時は、核の真上に Tier 0 が 1 個置いてある。真上を押して離すだけで最初の合体が起きる。

## 操作

- **押して離す**: 核へまっすぐ落とす（速さ 260）。
- **押したまま引いて離す**: 引いた向きへ投げる。引いた距離 24〜150px が速さ 200〜620 になる。外向きの成分は取り除かれる（輪に沿う向きまで）。天体は重力で曲がって落ちる。
- この変換は `src/shared/launch.ts` の `aimVelocity` にある。自分で計算し直さない。
- 押している間、**最初に何かへ触れるまでの道すじ**を出す（`Prediction`）。当たる相手が同じ Tier なら `willMerge` が true になる。予測は「いまの盤面が止まっている」と仮定した物で、その後の押しのけ合いは含まない。
- 撃った後、次に撃てるまで 0.5 秒。待っている間も照準はできる。

## 出来事（`GameEvent`）

| kind | いつ | 主な中身 |
|---|---|---|
| `launch` | 撃った | 場所、Tier |
| `land` | 撃った天体が初めて何かに触れた | 場所、Tier、`impactSpeed`（ぶつかった速さ） |
| `merge` | 合体した | 場所、元の Tier、生まれた Tier、`scoreDelta`、`chain` |
| `supernova` | Tier 8 どうしが消えた | 場所、`scoreDelta`、`heatDelta`（−40）、`chain` |
| `overLimitStart` | 山が限界リングを越えた | なし |
| `overLimitEnd` | 越えた天体がなくなった | なし |
| `gameOver` | 核熱量が 100 になった | なし |

盤面の状態（`GameSnapshot`）には、盤面全体の `overLimit` と、天体ごとの `overLimit` がある。どの天体が熱量を上げているかを見せるのに使う。

## 熱量の状態

25、50、75 を境に、安定・上昇・過熱・臨界（`src/shared/heat.ts` の `heatState`）。
